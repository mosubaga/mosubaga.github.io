## Project Overview
You are building an educational, interactive, and modern web site as the ultimate resource for creating web apps and web sites using **Codex**. The site should be a guide for people who are starting to use Codex for coding and building apps.

The target audience is developers and creators looking to maximize their efficiency with the Codex CLI tool. The site must explain workflow strategies, context management, and best practices for building complete applications through terminal-based AI collaboration.

## Core Features to Implement
1. **Interactive CLI Simulator:** A functional mock terminal component where users can click through common workflows and watch an interactive animation of Codex analyzing a repository, editing files, and running local builds.
2. **Architecture Blueprint Generator:** An interactive step-by-step panel where users select their app type (e.g., "Full-Stack SaaS", "Portfolio", "E-commerce Front-end") and Codex instantly renders a recommended folder structure, `AGENTS.md` context template, and starter prompting strategy on the screen.
3. **The Codex Workflow Loop:** A highly visual, looping component mapping the 4 key stages of a great Codex session:
   - **Context:** Passing files, tests, and documentation.
   - **Prompting:** Issuing granular, direct commands.
   - **Verification:** Automatically running local build/test commands.
   - **Iterating:** Using terminal error outputs to refine the code.
4. **Command & Slash Command Matrix:** A beautifully styled, filterable reference table detailing crucial slash commands, keyboard shortcuts, and flag parameters to optimize developer speed.
5. How to use Skills to improve code quality and productivity.
6. Using MCP to connect to external tools. List useful MCP to use for productivity.
