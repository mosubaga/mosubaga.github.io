### For Object Oriented Programming:

### Core Building Blocks
* Classes: A blueprint or template that defines the properties (data/attributes) and behaviors (methods) an object will have.
* Objects: An instance of a class created with specific data values.
* Attributes: The state or data values stored within an object.
* Methods: Functions defined inside a class that describe what an object can do.

### The Four Core Pillars of OOP
* Encapsulation: Bundling data and methods into a single unit (class) while restricting direct access to the internal state to prevent accidental corruption.
* Abstraction: Hiding complex internal logic and only exposing the essential features to the user.
* Inheritance: Allowing a new class (subclass) to inherit properties and behaviors from an existing class (superclass) to promote code reuse.
* Polymorphism: Allowing different classes to share the same method name or interface while executing their own specific behavior.

### For Functional Programming:

### Core Principles

* Pure Functions: Functions are deterministic—they always return the exact same output for the same input and cause zero side effects (like modifying global variables, writing to disks, or making network calls).
* Immutability: Data structures cannot be altered after creation. Instead of changing an existing value, functions produce new transformed data structures.
* First-Class and Higher-Order Functions: Functions are treated as primary values. You can pass them as arguments, return them from other functions, or store them in variables.
* Function Composition: Small, isolated functions are chained together to build complex data transformations.
* Recursion over Loops: Iteration is handled via recursive function calls instead of traditional mutable loop counters (like for or while loops).
