Foundations: Decomposing Signals into Frequencies

A periodic function \(f(x)\) of period \(2\pi\) can be written as a sum of sines and cosines — a Fourier series:

\[f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos(nx) + b_n\sin(nx)\bigr),\]

with coefficients recovered by the Euler formulas

\[a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos(nx)\,dx, \qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin(nx)\,dx.\]

If \(f\) meets the Dirichlet conditions on a period—periodicity, piecewise continuity (single-valued with finitely many jump discontinuities), finitely many extrema per period, and absolute integrability—the series converges to \(f(x)\) at every point of continuity, and to the average of the left- and right-hand limits, \(\tfrac12\bigl[f(x^-)+f(x^+)\bigr]\), at every jump.

For a non-periodic function, the analogous decomposition is the Fourier transform, which trades a discrete sum over integer frequencies for a continuous integral over all real frequencies \(\omega\). Using the symmetric convention,

\[\hat f(\omega) = \mathcal F\{f(x)\}(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} f(x)e^{-i\omega x}\,dx, \qquad f(x) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} \hat f(\omega)e^{i\omega x}\,d\omega.\]

The five problems below move from building a Fourier series by hand, to the subtleties of its convergence, to the transform's integral form, its operational rules, and finally its use in solving a driven differential equation.

Problem 1 — Fourier Series of a Sawtooth Wave

Scenario: Consider the periodic sawtooth function \(f(x)\) with period \(2\pi\), defined on its fundamental interval by

\[f(x) = x, \quad -\pi < x < \pi, \qquad f(x+2\pi) = f(x).\]

  1. Symmetry analysis: Is \(f(x)\) even, odd, or neither? Based on this, state which coefficients (\(a_0\), \(a_n\), or \(b_n\)) must vanish without integrating.
  2. Coefficient calculation: Evaluate the non-zero coefficients using \(b_n = \dfrac{1}{\pi}\displaystyle\int_{-\pi}^{\pi} f(x)\sin(nx)\,dx\), showing the integration-by-parts steps.
  3. Series construction: Write the complete trigonometric Fourier series for \(f(x)\) in summation notation.
  4. Conceptual question: Why do all cosine terms \(a_n\) vanish for an odd periodic function on a symmetric interval \([-\pi,\pi]\)?

Solution

1. \(f(-x) = -x = -f(x)\), so \(f\) is odd. An odd function has no cosine content, so \(a_0 = 0\) and \(a_n = 0\) for all \(n\); only the \(b_n\) can be non-zero.

2. Since \(x\sin(nx)\) is even, \(\displaystyle b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x\sin(nx)\,dx = \frac{2}{\pi}\int_0^{\pi} x\sin(nx)\,dx.\) Integrating by parts with \(u=x\), \(dv=\sin(nx)\,dx\), \(du=dx\), \(v=-\cos(nx)/n\):

\[\int_0^{\pi} x\sin(nx)\,dx = \left[-\frac{x\cos(nx)}{n}\right]_0^{\pi} + \int_0^{\pi}\frac{\cos(nx)}{n}\,dx = -\frac{\pi\cos(n\pi)}{n} + \left[\frac{\sin(nx)}{n^2}\right]_0^{\pi} = -\frac{\pi(-1)^n}{n}.\]

So \(\displaystyle b_n = \frac{2}{\pi}\cdot\left(-\frac{\pi(-1)^n}{n}\right) = \frac{2(-1)^{n+1}}{n}.\)

3. The series is

\[f(x) = \sum_{n=1}^{\infty}\frac{2(-1)^{n+1}}{n}\sin(nx) = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \dots\right).\]

4. A cosine term \(a_n\) requires integrating \(f(x)\cos(nx)\) over \([-\pi,\pi]\). Since \(f\) is odd and \(\cos(nx)\) is even, their product is odd, and the integral of any odd function over a symmetric interval is exactly zero — so every \(a_n\), including \(a_0\), vanishes automatically, with no integration needed.

The series above converges everywhere \(f\) is continuous, but the sawtooth itself jumps at \(x=\pm\pi\); the next problem studies precisely what a Fourier series does at such a jump.

Problem 2 — Dirichlet Conditions, Pointwise Convergence, and the Gibbs Phenomenon

Scenario: Consider the periodic square wave of period \(2\pi\)

\[g(x) = \begin{cases}-1, & -\pi \le x < 0\\ 1, & 0 \le x \le \pi\end{cases}, \qquad g(x) \sim \frac{4}{\pi}\sum_{k=0}^{\infty}\frac{\sin\bigl((2k+1)x\bigr)}{2k+1}.\]

  1. Dirichlet conditions: Verify that \(g(x)\) satisfies the four Dirichlet conditions on \([-\pi,\pi]\).
  2. Pointwise convergence: By Dirichlet's theorem, find the value the series converges to at \(x=\pi/2\) (continuity), \(x=0\) (jump), and \(x=\pi\) (boundary).
  3. Leibniz formula: Substitute \(x=\pi/2\) to derive \(1 - \tfrac13 + \tfrac15 - \tfrac17 + \dots = \tfrac{\pi}{4}\).
  4. Conceptual question: What happens to the partial sums \(S_N(x)\) near a jump discontinuity as \(N\to\infty\) (the Gibbs phenomenon)?

Solution

1. \(g\) is periodic with period \(2\pi\) by construction; it is single-valued and piecewise continuous, with exactly one jump per period (at \(x=0\), and the periodic identification of \(\pm\pi\)); it has a finite number of extrema per period (it is piecewise constant, so zero interior extrema); and it is absolutely integrable since \(\int_{-\pi}^{\pi}|g(x)|\,dx = 2\pi < \infty\). All four Dirichlet conditions hold.

2. At a point of continuity the series converges to \(g(x)\) itself; at a jump it converges to the average of the one-sided limits.

  • \(x=\pi/2\): \(g\) is continuous there with \(g(\pi/2)=1\), so the series converges to \(\mathbf{1}\).
  • \(x=0\): \(g(0^-) = -1\), \(g(0^+) = 1\), so the series converges to \(\tfrac{1}{2}(-1+1) = \mathbf{0}\).
  • \(x=\pi\): approaching from below, \(g\to 1\); by periodicity, approaching from above corresponds to \(x-2\pi \to -\pi^+\), where \(g\to -1\). The series converges to \(\tfrac12(1 + (-1)) = \mathbf{0}\).

3. Substituting \(x=\pi/2\) into the series, using \(\sin\bigl((2k+1)\pi/2\bigr) = (-1)^k\):

\[g\!\left(\frac{\pi}{2}\right) = 1 = \frac{4}{\pi}\sum_{k=0}^{\infty}\frac{(-1)^k}{2k+1} = \frac{4}{\pi}\left(1 - \frac13 + \frac15 - \frac17 + \dots\right).\]

Dividing both sides by \(4/\pi\):

\[1 - \frac13 + \frac15 - \frac17 + \dots = \frac{\pi}{4}.\]

4. Near a jump, the partial sums \(S_N(x)\) always overshoot the jump on either side by roughly \(9\%\) of the jump's size, no matter how large \(N\) is; increasing \(N\) does not shrink this overshoot, it only squeezes the oscillations closer to the discontinuity. So convergence is pointwise everywhere (per part 2) but not uniform near the jump — this persistent ringing is the Gibbs phenomenon.

A periodic signal decomposes into a discrete spectrum of harmonics \(n=1,2,3,\dots\); letting the period grow without bound turns that spectrum continuous, which is exactly the Fourier transform explored next.

Problem 3 — Fourier Transform of a Rectangular Pulse

Scenario: Consider the non-periodic rectangular pulse on \(\mathbb{R}\)

\[f(x) = \begin{cases}1, & |x|\le a\\ 0, & |x|>a\end{cases}, \qquad a>0.\]

  1. Direct calculation: Using \(\hat f(\omega) = \dfrac{1}{\sqrt{2\pi}}\displaystyle\int_{-\infty}^{\infty} f(x)e^{-i\omega x}\,dx\), show that \(\hat f(\omega) = \sqrt{\dfrac{2}{\pi}}\,\dfrac{\sin(a\omega)}{\omega} = \sqrt{\dfrac{2}{\pi}}\,a\,\text{sinc}(a\omega)\).
  2. Inverse transform: Write the inverse Fourier transform integral expression for \(f(x)\).
  3. Integral evaluation: Use the result to evaluate \(\displaystyle\int_0^{\infty}\frac{\sin(a\omega)\cos(\omega x)}{\omega}\,d\omega\) for \(|x|a\).
  4. Conceptual question: How does increasing the pulse width \(a\) affect the spread (bandwidth) of the spectrum \(\hat f(\omega)\)?

Solution

1. Since \(f\) is supported on \([-a,a]\),

\[\hat f(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-a}^{a} e^{-i\omega x}\,dx = \frac{1}{\sqrt{2\pi}}\int_{-a}^{a}\bigl[\cos(\omega x) - i\sin(\omega x)\bigr]dx.\]

The \(\sin(\omega x)\) term is odd and integrates to zero over the symmetric interval, leaving

\[\hat f(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-a}^{a}\cos(\omega x)\,dx = \frac{1}{\sqrt{2\pi}}\cdot\frac{2\sin(a\omega)}{\omega} = \sqrt{\frac{2}{\pi}}\,\frac{\sin(a\omega)}{\omega} = \sqrt{\frac{2}{\pi}}\,a\,\text{sinc}(a\omega).\]

2. \[f(x) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\hat f(\omega)e^{i\omega x}\,d\omega = \frac{1}{\pi}\int_{-\infty}^{\infty}\frac{\sin(a\omega)}{\omega}e^{i\omega x}\,d\omega.\]

3. Since \(\sin(a\omega)/\omega\) is an even function of \(\omega\), splitting \(e^{i\omega x} = \cos(\omega x) + i\sin(\omega x)\) makes the \(\sin(\omega x)\) piece odd overall (so it integrates to zero over \((-\infty,\infty)\)), leaving

\[f(x) = \frac{1}{\pi}\int_{-\infty}^{\infty}\frac{\sin(a\omega)\cos(\omega x)}{\omega}\,d\omega = \frac{2}{\pi}\int_0^{\infty}\frac{\sin(a\omega)\cos(\omega x)}{\omega}\,d\omega.\]

Solving for the integral, \(\displaystyle\int_0^{\infty}\frac{\sin(a\omega)\cos(\omega x)}{\omega}\,d\omega = \frac{\pi}{2}f(x)\), so using the original definition of \(f(x)\):

\[\int_0^{\infty}\frac{\sin(a\omega)\cos(\omega x)}{\omega}\,d\omega = \begin{cases}\dfrac{\pi}{2}, & |x|a.\end{cases}\]

4. Increasing \(a\) widens the pulse in space; the spectrum's main lobe has width proportional to \(1/a\), so it narrows as \(a\) grows. A wider pulse in space produces a narrower, more concentrated spectrum — and vice versa — the signature time–bandwidth trade-off of the Fourier transform.

Rather than recompute an integral like this one from scratch for every new function, it pays to build a toolkit of operational rules that transform a known spectrum into a new one — the subject of the next problem.

Problem 4 — Operational Properties: Scaling and Shifting

Scenario: Let \(h(x)\) have known Fourier transform \(\hat h(\omega) = \mathcal F\{h(x)\}(\omega)\).

  1. Shift property: Prove \(\mathcal F\{h(x-c)\}(\omega) = e^{-i\omega c}\hat h(\omega)\) for any real \(c\).
  2. Scaling property: Prove \(\mathcal F\{h(bx)\}(\omega) = \dfrac{1}{|b|}\hat h\!\left(\dfrac{\omega}{b}\right)\) for any non-zero real \(b\).
  3. Application: Given \(g(x) = e^{-|x|}\) with \(\hat g(\omega) = \sqrt{\dfrac{2}{\pi}}\,\dfrac{1}{1+\omega^2}\), apply scaling then shifting to find \(\hat v(\omega)\) for \(v(x) = e^{-|3x-6|}\).
  4. Conceptual question: What is the effect on \(\hat h(\omega)\) of multiplying \(h(x)\) by \(e^{i\omega_0 x}\) in the spatial domain?
Steps: derive the shift property with the substitution \(u=x-c\); derive the scaling property by treating \(b>0\) and \(b<0\) separately; rewrite \(v(x) = g\bigl(3(x-2)\bigr)\) and apply the two rules in sequence.

Solution

1. Shift property. Substitute \(u=x-c\) (so \(x=u+c\), \(dx=du\)):

\[\mathcal F\{h(x-c)\}(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} h(x-c)e^{-i\omega x}\,dx = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} h(u)e^{-i\omega(u+c)}\,du = e^{-i\omega c}\cdot\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} h(u)e^{-i\omega u}\,du = e^{-i\omega c}\hat h(\omega).\]

2. Scaling property. Substitute \(u=bx\) (\(x=u/b\), \(dx=du/b\)).

For \(b>0\), the limits of integration are unchanged, giving directly

\[\mathcal F\{h(bx)\}(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} h(u)e^{-i\omega u/b}\,\frac{du}{b} = \frac{1}{b}\hat h\!\left(\frac{\omega}{b}\right) = \frac{1}{|b|}\hat h\!\left(\frac{\omega}{b}\right).\]

For \(b<0\), as \(x\) runs from \(-\infty\) to \(\infty\), \(u=bx\) runs from \(+\infty\) down to \(-\infty\); reversing the limits back to the standard order contributes an extra minus sign that cancels the sign of \(1/b\):

\[\mathcal F\{h(bx)\}(\omega) = \frac{1}{\sqrt{2\pi}}\int_{\infty}^{-\infty} h(u)e^{-i\omega u/b}\,\frac{du}{b} = -\frac{1}{b}\hat h\!\left(\frac{\omega}{b}\right) = \frac{1}{|b|}\hat h\!\left(\frac{\omega}{b}\right),\]

since \(-1/b = 1/|b|\) when \(b<0\). Both cases agree: \(\mathcal F\{h(bx)\}(\omega) = \dfrac{1}{|b|}\hat h(\omega/b)\).

3. Application. Write \(v(x) = e^{-|3x-6|} = g\bigl(3(x-2)\bigr)\). First scale (\(b=3\)) to form \(w(x) = g(3x)\):

\[\hat w(\omega) = \frac{1}{3}\hat g\!\left(\frac{\omega}{3}\right) = \frac{1}{3}\sqrt{\frac{2}{\pi}}\cdot\frac{1}{1+(\omega/3)^2} = \sqrt{\frac{2}{\pi}}\cdot\frac{3}{9+\omega^2}.\]

Then shift (\(c=2\)) since \(v(x) = w(x-2)\):

\[\hat v(\omega) = e^{-2i\omega}\hat w(\omega) = 3\sqrt{\frac{2}{\pi}}\,\frac{e^{-2i\omega}}{9+\omega^2}.\]

4. Multiplying by \(e^{i\omega_0 x}\) in the spatial domain shifts the entire spectrum in frequency: \(\mathcal F\{h(x)e^{i\omega_0 x}\}(\omega) = \hat h(\omega-\omega_0)\) — the frequency-domain counterpart of the shift property, and the mechanism behind amplitude modulation.

These same series and transform tools are not just descriptive — a Fourier series can be substituted directly into a differential equation to build its solution, as the final problem shows.

Problem 5 — Fourier Series and a Forced Harmonic Oscillator

Scenario: A harmonic oscillator driven by a periodic force \(r(t)\) obeys

\[y''(t) + \omega_0^2\,y(t) = r(t),\]

where \(r(t)\), of period \(2\pi\), is defined on \([-\pi,\pi]\) by \(r(t) = |t|\), extended periodically.

  1. Fourier series of the load: Compute the Fourier cosine series of \(r(t)=|t|\), showing \(r(t) = \dfrac{\pi}{2} - \dfrac{4}{\pi}\displaystyle\sum_{n=1,3,5,\dots}^{\infty}\dfrac{\cos(nt)}{n^2}\).
  2. Harmonic response: Assume \(y_p(t) = \dfrac{A_0}{2} + \displaystyle\sum_{n=1}^{\infty} A_n\cos(nt)\); substitute into the ODE and solve for \(A_0\) and \(A_n\) in terms of \(n\) and \(\omega_0\).
  3. Solution expression: Write the complete steady-state response \(y_p(t)\), assuming \(\omega_0 \ne 1,3,5,\dots\).
  4. Conceptual question: What happens physically if \(\omega_0\) approaches one of the odd harmonics \(n\in\{1,3,5,\dots\}\) of the driving force?

Solution

1. \(r(t)=|t|\) is even, so \(b_n=0\) and only \(a_0,a_n\) survive.

\[a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi}|t|\,dt = \frac{2}{\pi}\int_0^{\pi} t\,dt = \frac{2}{\pi}\cdot\frac{\pi^2}{2} = \pi \quad\Longrightarrow\quad \frac{a_0}{2} = \frac{\pi}{2}.\]

For \(a_n\), integrate by parts with \(u=t\), \(dv=\cos(nt)\,dt\):

\[\int_0^{\pi} t\cos(nt)\,dt = \left[\frac{t\sin(nt)}{n}\right]_0^{\pi} + \left[\frac{\cos(nt)}{n^2}\right]_0^{\pi} = 0 + \frac{(-1)^n-1}{n^2}.\]

\[a_n = \frac{2}{\pi}\cdot\frac{(-1)^n-1}{n^2}.\]

For even \(n\), \((-1)^n-1=0\), so \(a_n=0\). For odd \(n\), \((-1)^n-1=-2\), so \(a_n = -\dfrac{4}{\pi n^2}\). Hence

\[r(t) = \frac{\pi}{2} + \sum_{n=1,3,5,\dots}^{\infty}\left(-\frac{4}{\pi n^2}\right)\cos(nt) = \frac{\pi}{2} - \frac{4}{\pi}\sum_{n=1,3,5,\dots}^{\infty}\frac{\cos(nt)}{n^2}.\]

2. Differentiating \(y_p\) twice, \(y_p''(t) = -\sum_n A_n n^2\cos(nt)\). Substituting into the ODE:

\[\frac{\omega_0^2 A_0}{2} + \sum_{n=1}^{\infty}(\omega_0^2-n^2)A_n\cos(nt) = \frac{\pi}{2} - \frac{4}{\pi}\sum_{n=1,3,5,\dots}^{\infty}\frac{\cos(nt)}{n^2}.\]

Matching the constant term: \(\dfrac{\omega_0^2 A_0}{2} = \dfrac{\pi}{2} \Rightarrow A_0 = \dfrac{\pi}{\omega_0^2}.\) Matching \(\cos(nt)\) coefficients for odd \(n\): \((\omega_0^2-n^2)A_n = -\dfrac{4}{\pi n^2} \Rightarrow A_n = \dfrac{4}{\pi n^2(n^2-\omega_0^2)}\). For even \(n\) the right-hand side has no \(\cos(nt)\) term, so \(A_n = 0\).

3. Provided \(\omega_0\) is not an odd integer (so no denominator vanishes),

\[y_p(t) = \frac{\pi}{2\omega_0^2} + \frac{4}{\pi}\sum_{n=1,3,5,\dots}^{\infty}\frac{\cos(nt)}{n^2(n^2-\omega_0^2)}.\]

4. If \(\omega_0\) approaches an odd integer \(n\), the factor \((n^2-\omega_0^2)\) in \(A_n\) approaches zero, so that harmonic's amplitude \(A_n\) grows without bound — the classic resonance phenomenon, where the driving force's \(n\)-th harmonic pumps energy into the oscillator's natural mode with no restoring balance in an undamped system.

From a single sawtooth's coefficients to a resonance condition inside a differential equation, every step used the same two ideas: matching symmetry to kill half the coefficients, and matching frequency components term by term.
