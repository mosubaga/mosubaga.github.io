Problem 1: Gauss's (Divergence) Theorem — Flux Across a Closed Cube

Topic: Gauss's (Divergence) Theorem

Statement

Let \(E\) be the solid unit cube bounded by the coordinate planes and the planes \(x = 1\), \(y = 1\), and \(z = 1\), so \(E = \{(x,y,z) \mid 0 \le x \le 1, 0 \le y \le 1, 0 \le z \le 1\}\). Let \(S = \partial E\) be the boundary surface of the cube with outward unit normal vector \(\mathbf{n}\). Consider the vector field: \[\mathbf{F}(x, y, z) = \langle 3x, xy, 2xz \rangle\]

  1. Compute the divergence \(\operatorname{div} \mathbf{F} = \nabla \cdot \mathbf{F}\) explicitly.
  2. Apply Gauss's (Divergence) Theorem to evaluate the outward flux \(\iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \iiint_E \operatorname{div} \mathbf{F} \, dV\).
  3. Verify the result by directly calculating the flux across each of the 6 square faces of the cube.

Solution Steps

  1. Compute Divergence: \[\operatorname{div} \mathbf{F} = \frac{\partial}{\partial x}(3x) + \frac{\partial}{\partial y}(xy) + \frac{\partial}{\partial z}(2xz) = 3 + x + 2x = 3 + 3x\].
  2. Apply Divergence Theorem: \[\iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \int_0^1 \int_0^1 \int_0^1 (3 + 3x) \, dz \, dy \, dx\]. \[\int_0^1 (3 + 3x) \, dx = \left[ 3x + \frac{3}{2}x^2 \right]_0^1 = 3 + \frac{3}{2} = \frac{9}{2}\].
  3. Direct Verification across 6 Faces:
    • Front (\(x=1, \mathbf{n}=\mathbf{i}\)): \(\int_0^1 \int_0^1 F_1(1,y,z) \, dy \, dz = \int_0^1 \int_0^1 3 \, dy \, dz = 3\).
    • Back (\(x=0, \mathbf{n}=-\mathbf{i}\)): \(\int_0^1 \int_0^1 -F_1(0,y,z) \, dy \, dz = 0\).
    • Right (\(y=1, \mathbf{n}=\mathbf{j}\)): \(\int_0^1 \int_0^1 F_2(x,1,z) \, dx \, dz = \int_0^1 \int_0^1 x \, dx \, dz = \frac{1}{2}\).
    • Left (\(y=0, \mathbf{n}=-\mathbf{j}\)): \(\int_0^1 \int_0^1 -F_2(x,0,z) \, dx \, dz = 0\).
    • Top (\(z=1, \mathbf{n}=\mathbf{k}\)): \(\int_0^1 \int_0^1 F_3(x,y,1) \, dx \, dy = \int_0^1 \int_0^1 2x \, dx \, dy = 1\).
    • Bottom (\(z=0, \mathbf{n}=-\mathbf{k}\)): \(\int_0^1 \int_0^1 -F_3(x,y,0) \, dx \, dy = 0\).
    • Total Flux: \(3 + 0 + \frac{1}{2} + 0 + 1 + 0 = \frac{9}{2}\).

Answer

\[\operatorname{div} \mathbf{F} = 3 + 3x; \quad \iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \frac{9}{2}\]

Problem 2: Gauss's (Divergence) Theorem — Flux Through a Solid Cylinder

Topic: Gauss's (Divergence) Theorem

Statement

Let \(E\) be the solid cylinder bounded by \(x^2 + y^2 \le 4\), \(z = 0\), and \(z = 3\). Let \(S\) be the complete boundary surface of \(E\) oriented with outward normal \(\mathbf{n}\). Given the vector field: \[\mathbf{F}(x, y, z) = \langle x^3 + y, y^3 - x, z^2 \rangle\]

  1. Compute \(\operatorname{div} \mathbf{F}\) in Cartesian coordinates.
  2. Set up the triple integral for flux over \(E\) in cylindrical coordinates \((r, \theta, z)\).
  3. Evaluate the total outward flux \(\iint_S \mathbf{F} \cdot \mathbf{n} \, dS\).

Solution Steps

  1. Compute Divergence: \[\operatorname{div} \mathbf{F} = \frac{\partial}{\partial x}(x^3 + y) + \frac{\partial}{\partial y}(y^3 - x) + \frac{\partial}{\partial z}(z^2) = 3x^2 + 3y^2 + 2z\].
  2. Convert to Cylindrical Coordinates: In cylindrical coordinates, \(x^2 + y^2 = r^2\) and \(dV = r \, dz \, dr \, d\theta\). The region \(E\) is defined by \(0 \le r \le 2\), \(0 \le \theta \le 2\pi\), and \(0 \le z \le 3\). \[\operatorname{div} \mathbf{F} = 3r^2 + 2z\]
  3. Evaluate Integral: \[\iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \int_0^{2\pi} \int_0^2 \int_0^3 (3r^2 + 2z) r \, dz \, dr \, d\theta\]
    • Inner integral with respect to \(z\): \[\int_0^3 (3r^3 + 2rz) \, dz = \left[ 3r^3 z + r z^2 \right]_0^3 = 9r^3 + 9r\]
    • Middle integral with respect to \(r\): \[\int_0^2 (9r^3 + 9r) \, dr = \left[ \frac{9}{4}r^4 + \frac{9}{2}r^2 \right]_0^2 = \frac{9}{4}(16) + \frac{9}{2}(4) = 36 + 18 = 54\]
    • Outer integral with respect to \(\theta\): \[\int_0^{2\pi} 54 \, d\theta = 108\pi\]

Answer

\[\operatorname{div} \mathbf{F} = 3(x^2 + y^2) + 2z; \quad \iint_S \mathbf{F} \cdot \mathbf{n} \, dS = 108\pi\]

Problem 3: Stokes' Theorem — Circulation Around a Paraboloid Boundary

Topic: Stokes' Theorem

Statement

Let \(S\) be the surface of the paraboloid \(z = 4 - x^2 - y^2\) for \(z \ge 0\), oriented with an upward unit normal vector \(\mathbf{n}\). The boundary curve \(C = \partial S\) is the circle \(x^2 + y^2 = 4\) in the plane \(z = 0\), traversed counterclockwise when viewed from above. Consider the vector field: \[\mathbf{F}(x, y, z) = \langle -y, x, z^2 \rangle\]

  1. Compute the curl of the vector field \(\operatorname{curl} \mathbf{F} = \nabla \times \mathbf{F}\).
  2. Set up and evaluate the surface integral \(\iint_S (\operatorname{curl} \mathbf{F}) \cdot \mathbf{n} \, dS\) using Stokes' Theorem.
  3. Verify the result by evaluating the line integral \(\oint_C \mathbf{F} \cdot d\mathbf{r}\) directly via a parameterization of \(C\).

Solution Steps

  1. Compute Curl: \[\operatorname{curl} \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ -y & x & z^2 \end{vmatrix} = \langle 0 - 0, 0 - 0, 1 - (-1) \rangle = \langle 0, 0, 2 \rangle\].
  2. Surface Integral via Stokes' Theorem: For a surface given as \(z = g(x,y) = 4 - x^2 - y^2\), the upward normal vector element is \(d\mathbf{S} = \mathbf{n} \, dS = \langle -g_x, -g_y, 1 \rangle \, dA = \langle 2x, 2y, 1 \rangle \, dA\). \[\iint_S (\operatorname{curl} \mathbf{F}) \cdot \mathbf{n} \, dS = \iint_{x^2+y^2 \le 4} \langle 0, 0, 2 \rangle \cdot \langle 2x, 2y, 1 \rangle \, dA = \iint_{x^2+y^2 \le 4} 2 \, dA\]. The area of the disk \(x^2 + y^2 \le 4\) is \(\pi (2^2) = 4\pi\). Therefore, the surface integral equals \(2 \times 4\pi = 8\pi\).
  3. Direct Line Integral Verification: Parameterize \(C\): \(\mathbf{r}(t) = \langle 2\cos t, 2\sin t, 0 \rangle\) for \(0 \le t \le 2\pi\). Then \(d\mathbf{r} = \langle -2\sin t, 2\cos t, 0 \rangle \, dt\). \(\mathbf{F}(\mathbf{r}(t)) = \langle -2\sin t, 2\cos t, 0 \rangle\). \[\oint_C \mathbf{F} \cdot d\mathbf{r} = \int_0^{2\pi} \left( (-2\sin t)(-2\sin t) + (2\cos t)(2\cos t) + 0 \right) dt = \int_0^{2\pi} 4 (\sin^2 t + \cos^2 t) \, dt = \int_0^{2\pi} 4 \, dt = 8\pi\].

Answer

\[\operatorname{curl} \mathbf{F} = \langle 0, 0, 2 \rangle; \quad \oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S (\operatorname{curl} \mathbf{F}) \cdot \mathbf{n} \, dS = 8\pi\]

Problem 4: Stokes' Theorem — Work Done Around a Triangular Path

Topic: Stokes' Theorem

Statement

Let \(C\) be the triangular path in \(\mathbb{R}^3\) connecting the vertices \((1,0,0) \to (0,1,0) \to (0,0,1) \to (1,0,0)\) in order, bounding the planar surface \(S\) given by \(x + y + z = 1\) in the first octant. Orient \(S\) with the upward unit normal \(\mathbf{n}\). Given the force field: \[\mathbf{F}(x, y, z) = \langle x + y^2, y + z^2, z + x^2 \rangle\]

  1. Calculate \(\operatorname{curl} \mathbf{F}\).
  2. Parameterize the surface \(S\) and compute the upward normal vector \(\mathbf{N} = \mathbf{n} \, dS\).
  3. Apply Stokes' Theorem to find the work done \(W = \oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S (\operatorname{curl} \mathbf{F}) \cdot \mathbf{n} \, dS\).

Solution Steps

  1. Calculate Curl: \[\operatorname{curl} \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ x + y^2 & y + z^2 & z + x^2 \end{vmatrix} = \langle 0 - 2z, 0 - 2x, 0 - 2y \rangle = -2 \langle z, x, y \rangle\].
  2. Parameterize Surface and Normal: The surface is \(z = 1 - x - y\) over the region \(D = \{(x,y) \mid x \ge 0, y \ge 0, x + y \le 1\}\). The upward vector differential is \(d\mathbf{S} = \langle -\frac{\partial z}{\partial x}, -\frac{\partial z}{\partial y}, 1 \rangle \, dA = \langle 1, 1, 1 \rangle \, dA\).
  3. Evaluate Surface Integral: Substitute \(z = 1 - x - y\) into \(\operatorname{curl} \mathbf{F}\): \[\operatorname{curl} \mathbf{F} \cdot d\mathbf{S} = \langle -2(1-x-y), -2x, -2y \rangle \cdot \langle 1, 1, 1 \rangle \, dA = -2(1 - x - y + x + y) \, dA = -2 \, dA\]. \[\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_D (-2) \, dA = -2 \cdot \operatorname{Area}(D)\]. Since \(D\) is a right triangle with base \(1\) and height \(1\), \(\operatorname{Area}(D) = \frac{1}{2}(1)(1) = \frac{1}{2}\). \[W = -2 \left( \frac{1}{2} \right) = -1\]

Answer

\[\operatorname{curl} \mathbf{F} = \langle -2z, -2x, -2y \rangle; \quad W = \oint_C \mathbf{F} \cdot d\mathbf{r} = -1\]

Problem 5: Computational Efficiency Comparison — Gauss vs. Direct Method

Topic: Gauss's Theorem / Method Selection for Efficiency

Statement

A student is asked to calculate the outward flux \(\iint_S \mathbf{F} \cdot \mathbf{n} \, dS\) of the vector field: \[\mathbf{F}(x, y, z) = \langle x^3 + e^{y z}, y^3 + \sin(xz), z^3 + \tan^{-1}(xy) \rangle\] across the closed surface \(S\) of the unit sphere \(x^2 + y^2 + z^2 = 1\).

  1. Compare Approaches: Compare computing the flux directly via surface parameterization versus using Gauss's (Divergence) Theorem in terms of computational complexity and effort.
  2. Identify the Efficient Method: State which method is preferable and explain why.
  3. Execute Solution: Using the chosen efficient method, show all step-by-step calculations to determine the exact flux.

Solution Steps

  1. Comparison of Methods:
    • Direct Method: Requires parameterizing the spherical surface \(S\), computing normal vectors \(\mathbf{n}\), and evaluating \(\iint_S \mathbf{F} \cdot \mathbf{n} \, dS\) directly with complicated transcendental components like \(e^{yz}\), \(\sin(xz)\), and \(\tan^{-1}(xy)\) on the sphere.
    • Divergence Theorem: Relates flux to the volume integral \(\iiint_E \operatorname{div} \mathbf{F} \, dV\). Differentiating \(\mathbf{F}\) completely eliminates all complex cross-terms (\(e^{yz}, \sin(xz), \tan^{-1}(xy)\)) because \(\frac{\partial}{\partial x}(e^{yz}) = 0\), \(\frac{\partial}{\partial y}(\sin(xz)) = 0\), and \(\frac{\partial}{\partial z}(\tan^{-1}(xy)) = 0\).
  2. Method Selection: Gauss's (Divergence) Theorem is vastly superior because it reduces a complicated surface integral with transcendental terms to a simple, highly symmetric triple integral over a solid sphere.
  3. Execution via Divergence Theorem:
    • Compute Divergence: \[\operatorname{div} \mathbf{F} = \frac{\partial}{\partial x}(x^3 + e^{yz}) + \frac{\partial}{\partial y}(y^3 + \sin(xz)) + \frac{\partial}{\partial z}(z^3 + \tan^{-1}(xy)) = 3x^2 + 3y^2 + 3z^2\].
    • Set Up in Spherical Coordinates: Using spherical coordinates where \(x^2 + y^2 + z^2 = \rho^2\) and \(dV = \rho^2 \sin \phi \, d\rho \, d\phi \, d\theta\) over \(0 \le \rho \le 1, 0 \le \phi \le \pi, 0 \le \theta \le 2\pi\). \[\iiint_E 3(x^2 + y^2 + z^2) \, dV = \int_0^{2\pi} \int_0^\pi \int_0^1 3\rho^2 \cdot \rho^2 \sin \phi \, d\rho \, d\phi \, d\theta\].
    • Evaluate Integral: \[\int_0^1 3\rho^4 \, d\rho = \left[ \frac{3}{5}\rho^5 \right]_0^1 = \frac{3}{5}\] \[\int_0^\pi \sin \phi \, d\phi = 2\] \[\int_0^{2\pi} d\theta = 2\pi\] \[\text{Total Flux} = \frac{3}{5} \times 2 \times 2\pi = \frac{12\pi}{5}\].

Answer

Gauss's Theorem is chosen because \(\operatorname{div} \mathbf{F} = 3(x^2 + y^2 + z^2)\) eliminates transcendental terms. The exact total flux is: \[\iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \frac{12\pi}{5}\]
