## Objective

Pleas create a website that talks about Tchaikovsky nutcracker (the ballet )

# Working directory and Output

`/Users/nobuhikohayashi/Projects/mosubaga.github.io/nutcracker`

This is where the website has to be.

# Structure

The website should have a following page:

1. index.html - Landing page. Brief introduction to the ballet and a quick history of the ballet.
2. story.html - The story (or what the show is about)
3. cast.html - List of casts (with explanation)
4. info.html - Some `trivia` audience should know about the show.

# Stack

1. Please use HTML, CSS, Javascript for this page. No need to use React or other framework.
2. Each please use the css file in the `css` folder for style.
3. On each page, please create an artwork that resembles the scene from the nutcracker ballet. Please use p5.js and store those js file under the `js` folder.

# Things to keep in mind

- Although the style is set, please think about that the show will be on Christmas so please think about that when creating the website.
- Please make the website engaging to ALL age groups.
- This page can be read through iphone or ipad. If necessary, please feel free to make changes to the style if necessary to fit into iphone or ipad.
