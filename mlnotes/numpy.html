Library guide · Foundations

NumPy

Fast arrays, vectorised maths and linear algebra: the foundation that every other ML library is built on.

NumPy (Numerical Python) is the fundamental package for scientific computing in Python. It provides large, multi-dimensional arrays and matrices, along with a collection of mathematical functions that operate on them efficiently. NumPy is the backbone of nearly all machine learning libraries in Python: pandas, SciPy, scikit-learn and TensorFlow all speak NumPy arrays.

pip install numpy

Why NumPy is Essential for Machine Learning

NumPy serves as the foundation for machine learning in Python because it provides:

  • Efficient array operations: Arrays are stored in contiguous memory blocks, making operations far faster than Python lists.
  • Vectorisation: Operate on entire arrays without explicit loops, giving cleaner and faster code.
  • Mathematical functions: Built-in linear algebra, statistics and element-wise maths.
  • Broadcasting: Automatic expansion of arrays to compatible shapes for arithmetic.
  • Memory efficiency: Typed arrays consume far less memory than Python lists of numbers.

What's changed in modern NumPy (2.x)

  • Use the Generator API: rng = np.random.default_rng(seed) and rng.normal(...), rng.integers(...). The legacy np.random.rand / np.random.seed functions still work but are no longer recommended for new code.
  • Removed aliases: use np.float64, np.nan and np.inf instead of np.float_, np.NaN and np.Inf.
  • Prefer np.linalg.lstsq or np.linalg.solve to explicitly computing np.linalg.inv: they are faster and numerically more stable.

Core Concepts in NumPy

1. NumPy Arrays (ndarray)

The ndarray is the core data structure in NumPy: a grid of values, all of the same type, indexed by a tuple of non-negative integers. Arrays can be created from Python lists or with built-in constructors.

Creating arrays:
  • np.array([1, 2, 3]) - from a list
  • np.zeros((3, 4)) / np.ones((2, 3)) - filled with zeros or ones
  • np.arange(0, 10, 2) - evenly spaced values by step
  • np.linspace(0, 1, 5) - a fixed number of evenly spaced samples
  • rng.random((3, 3)), rng.normal(size=(100, 3)) - random values from a Generator
import numpy as np

rng = np.random.default_rng(seed=42)   # modern, reproducible random API

a = np.array([1, 2, 3])
zeros = np.zeros((3, 4))
steps = np.arange(0, 10, 2)
grid = np.linspace(0, 1, 5)
X = rng.normal(loc=0.0, scale=1.0, size=(100, 3))   # 100 samples x 3 features

print(a.dtype, zeros.shape, steps, grid)
print(X.shape, X.mean(axis=0).round(3))

2. Array Operations and Vectorisation

Vectorisation lets you perform operations on entire arrays without writing explicit loops. This is crucial in machine learning, where the same operation is applied to millions of values.

Key operations:
  • Element-wise operations: +, -, *, /, ** on whole arrays
  • Aggregations: np.sum(), np.mean(), np.std(), np.max(), np.min(), with an axis argument
  • Universal functions: np.sqrt(), np.exp(), np.log(), np.sin()
  • Matrix operations: the @ operator (or np.matmul) and .T for transpose

The example below doubles a million numbers with a Python loop and with a vectorised expression. The vectorised version is typically dozens of times faster (the exact ratio depends on your machine).

import time
import numpy as np

rng = np.random.default_rng(0)
values = rng.random(1_000_000)

start = time.perf_counter()
loop_total = sum(v * 2.0 for v in values)
loop_time = time.perf_counter() - start

start = time.perf_counter()
vec_total = (values * 2.0).sum()
vec_time = time.perf_counter() - start

print(f"loop: {loop_time:.4f}s  vectorized: {vec_time:.4f}s")
print("same result:", np.isclose(loop_total, vec_total))

3. Array Indexing and Slicing

NumPy's indexing tools are essential for selecting samples, features and subsets of data in ML workflows.

Indexing techniques:
  • Basic indexing: arr[0] or arr[1, 2]
  • Slicing: arr[start:stop:step], arr[:, 1] for a whole column
  • Boolean indexing: filter with conditions like arr[arr > 5]
  • Fancy indexing: select rows with an array of indices, arr[[2, 0]]
import numpy as np

# rows = students, columns = exams
scores = np.array([[88, 92, 79],
                   [65, 70, 58],
                   [95, 98, 91],
                   [72, 60, 85]])

print(scores[0])            # first student
print(scores[:, 1])         # second exam for everyone
print(scores[scores > 90])  # every score above 90

passed_all = (scores >= 60).all(axis=1)
print("students who passed every exam:", np.flatnonzero(passed_all))

print(scores[[2, 0]])       # fancy indexing: rows 2 and 0

NumPy in Machine Learning Workflows

Data Representation

Datasets are stored as 2-D arrays of shape (samples, features), with labels as 1-D arrays.

Feature Normalisation

(X - X.mean(axis=0)) / X.std(axis=0) standardises every column in one line, thanks to broadcasting.

Matrix Operations

Linear regression, neural networks and PCA are built from matrix products like X @ w.

Random Numbers

Weight initialisation, shuffling, train/test splits and bootstrapping all rely on np.random.default_rng.

Statistics

Means, variances, percentiles, covariances and correlations (np.corrcoef) power exploratory analysis.

Efficient Computation

C-based loops and SIMD instructions make it practical to process millions of data points.

Advanced NumPy for Machine Learning

Broadcasting

Broadcasting lets NumPy combine arrays of different shapes. Subtracting a per-feature mean of shape (3,) from a dataset of shape (200, 3) applies it to every row automatically. The example standardises features and then performs a reproducible train/test split.

import numpy as np

rng = np.random.default_rng(7)
X = rng.normal(loc=[50, 0.5, 1000], scale=[10, 0.1, 250], size=(200, 3))
y = (X[:, 0] + 100 * X[:, 1] > 100).astype(int)

# Broadcasting: (200, 3) minus (3,) is applied column by column
X_std = (X - X.mean(axis=0)) / X.std(axis=0)
print(X_std.mean(axis=0).round(6), X_std.std(axis=0).round(6))

# Shuffle and split without any ML library
idx = rng.permutation(len(X))
split = int(0.8 * len(X))
train_idx, test_idx = idx[:split], idx[split:]
X_train, X_test = X_std[train_idx], X_std[test_idx]
y_train, y_test = y[train_idx], y[test_idx]
print(X_train.shape, X_test.shape, y_train.mean().round(2))

Linear Algebra Module (numpy.linalg)

The numpy.linalg module solves linear systems, computes eigenvalues and eigenvectors, performs decompositions (SVD, QR, Cholesky) and computes norms. These are the building blocks of many ML algorithms.

Key linear algebra functions:
  • np.linalg.lstsq() - least-squares solution (linear regression)
  • np.linalg.solve() - solve Ax = b without forming an inverse
  • np.linalg.eigh() - eigen-decomposition of symmetric matrices (covariance, PCA)
  • np.linalg.svd() - Singular Value Decomposition
  • np.linalg.norm() - vector or matrix norms (distances, regularisation)

Example: linear regression from scratch

import numpy as np

rng = np.random.default_rng(1)
n = 500
sqft = rng.uniform(500, 3500, n)
bedrooms = rng.integers(1, 6, n)
price = 50_000 + 120 * sqft + 15_000 * bedrooms + rng.normal(0, 20_000, n)

# Design matrix with a bias (intercept) column
X = np.column_stack([np.ones(n), sqft, bedrooms])

# lstsq is numerically safer than np.linalg.inv(X.T @ X) @ X.T @ y
coef, *_ = np.linalg.lstsq(X, price, rcond=None)
print("intercept, per-sqft, per-bedroom:", coef.round(1))

pred = X @ coef
rmse = np.sqrt(np.mean((price - pred) ** 2))
print(f"RMSE: {rmse:,.0f}")

Example: PCA with the SVD

Five measured features that really only vary along two hidden directions: the explained-variance ratio reveals it.

import numpy as np

rng = np.random.default_rng(3)
latent = rng.normal(size=(300, 2))
mixing = rng.normal(size=(2, 5))
X = latent @ mixing + 0.05 * rng.normal(size=(300, 5))  # 5 features, ~2 real dimensions

X_centered = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)

explained = S**2 / np.sum(S**2)
print("explained variance ratio:", explained.round(3))

X_2d = X_centered @ Vt[:2].T    # project onto the top-2 components
print(X_2d.shape)

Performance and Memory

  • Avoid loops: use vectorised operations instead of Python for loops.
  • Use in-place operations: X -= X.mean(axis=0) avoids allocating a new array.
  • Choose data types: float32 halves memory compared to float64 and is the default in deep learning.
  • Leverage views: slicing returns a view, not a copy. Call .copy() only when you need one.
  • Save arrays efficiently: np.save / np.savez_compressed are faster and smaller than CSV.
import numpy as np

rng = np.random.default_rng(0)
X = rng.random((1000, 20), dtype=np.float32)   # float32 halves memory vs float64
y = rng.integers(0, 2, size=1000)

np.savez_compressed("dataset.npz", X=X, y=y)

data = np.load("dataset.npz")
print(data["X"].shape, data["X"].dtype, data["y"][:10])
print(f"{X.nbytes / 1024:.0f} KiB in memory")

NumPy Best Practices for ML

1. Always vectorise: replace Python loops with NumPy operations whenever possible.

2. Understand shapes: print .shape often to avoid broadcasting surprises.

3. Seed a Generator: pass default_rng(seed) around for reproducible experiments.

4. Pick appropriate dtypes: choose int32, float32 or float64 deliberately.

5. Profile your code: use time.perf_counter() or %timeit to find bottlenecks.
