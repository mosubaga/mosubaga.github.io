SciPy

Optimisers, statistical tests, sparse matrices and signal processing: the scientific toolbox behind many ML methods.

SciPy is an open-source library for mathematics, science and engineering, built on top of NumPy. It provides efficient implementations of algorithms for optimisation, statistics, linear algebra, signal processing, interpolation, integration, sparse matrices and more. While libraries like scikit-learn provide high-level ML APIs, SciPy supplies many of the computational building blocks those libraries rely on, and it is invaluable when you need low-level control in ML workflows.

pip install scipy

Why SciPy is Useful for Machine Learning

SciPy complements NumPy and scikit-learn by offering:

  • Optimisation routines: solvers for minimising custom loss functions and fitting models.
  • Statistical tools: distributions, hypothesis tests, bootstrapping and density estimation for EDA and validation.
  • Linear algebra & sparse data: high-performance dense and sparse matrix operations.
  • Signal & image processing: filtering, spectral features and transforms for audio, sensor and image tasks.
  • Interoperability: works directly with NumPy arrays and scikit-learn estimators.

Updated for current SciPy (1.15+)

  • interp2d has been removed. Use RegularGridInterpolator for gridded data or RBFInterpolator / griddata for scattered points.
  • interp1d and Rbf are legacy. Prefer make_interp_spline, np.interp and RBFInterpolator.
  • Sparse arrays (csr_array, sparse.random_array) are now recommended over the older *_matrix classes. They behave like NumPy arrays (* is element-wise, @ is matrix product).
  • KDTree and cKDTree are now the same fast implementation, so just use KDTree.

Core SciPy Modules for ML

1. Optimisation (scipy.optimize)

Use scipy.optimize to minimise custom loss functions, fit models, or solve constrained problems when out-of-the-box estimators are not suitable.

Common techniques:
  • minimize(fun, x0, method=...) - general-purpose minimisation (L-BFGS-B, BFGS, Nelder-Mead, trust-constr, ...)
  • least_squares(fun, x0, ...) - non-linear least squares with robust loss options
  • curve_fit(f, x, y) - non-linear curve fitting (wraps least_squares)
  • linprog / milp - linear and mixed-integer linear programming

Example: fit a non-linear curve

import numpy as np
from scipy.optimize import curve_fit

def model(x, a, b, c):
    return a * np.exp(-b * x) + c

rng = np.random.default_rng(0)
x = np.linspace(0, 4, 50)
y = model(x, 2.5, 1.3, 0.5) + 0.2 * rng.normal(size=x.size)

popt, pcov = curve_fit(model, x, y, p0=[1, 1, 0])
perr = np.sqrt(np.diag(pcov))          # 1-sigma uncertainty of each parameter
print("a, b, c =", popt.round(3))
print("std err =", perr.round(3))

Example: train a regularised logistic regression with your own loss

Returning the gradient together with the loss (jac=True) lets L-BFGS-B converge in a few iterations, which is exactly how many scikit-learn models are trained internally.

import numpy as np
from scipy.optimize import minimize
from scipy.special import expit       # numerically stable sigmoid

rng = np.random.default_rng(42)
X = rng.normal(size=(400, 3))
true_w = np.array([2.0, -1.0, 0.5])
y = (rng.random(400) < expit(X @ true_w)).astype(float)

def loss_and_grad(w, X, y, l2=0.01):
    """L2-regularised logistic loss and its gradient."""
    p = expit(X @ w)
    eps = 1e-12
    loss = -np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps)) + l2 * w @ w
    grad = X.T @ (p - y) / len(y) + 2 * l2 * w
    return loss, grad

result = minimize(loss_and_grad, x0=np.zeros(3), args=(X, y), jac=True, method="L-BFGS-B")
print("converged:", result.success, "| weights:", result.x.round(3))

2. Statistics (scipy.stats)

scipy.stats provides distributions, random variates, descriptive statistics, hypothesis tests and kernel density estimation for EDA, feature analysis and model validation.

Key features:
  • Distributions: stats.norm, stats.beta, stats.poisson, ... with .pdf(), .cdf(), .rvs()
  • Hypothesis tests: ttest_ind, mannwhitneyu, chi2_contingency, ks_2samp
  • Correlation: pearsonr, spearmanr, kendalltau
  • Resampling: bootstrap, permutation_test for confidence intervals without distribution assumptions
  • Density estimation: gaussian_kde

Example: analyse an A/B test

import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
# Session length (minutes) for the old and new page design
control = rng.normal(loc=5.0, scale=1.5, size=200)
variant = rng.normal(loc=5.4, scale=1.5, size=200)

t_stat, p_val = stats.ttest_ind(control, variant, equal_var=False)  # Welch's t-test
print(f"Welch t = {t_stat:.2f}, p = {p_val:.4f}")

# Conversion counts: [converted, not converted]
table = np.array([[120, 880],    # control
                  [150, 850]])   # variant
chi2, p, dof, expected = stats.chi2_contingency(table)
print(f"chi-square p-value = {p:.4f}")

# Bootstrap 95% confidence interval for the difference in means
res = stats.bootstrap((variant, control), lambda a, b: np.mean(a) - np.mean(b),
                      n_resamples=2000, random_state=rng)
print("95% CI for uplift:", np.round(res.confidence_interval, 3))

3. Linear Algebra (scipy.linalg)

High-level linear algebra routines similar to NumPy's linalg, with more algorithms and performance options.

Useful routines:
  • svd, eigh / eig - decompositions used in PCA and spectral methods
  • solve, lu_factor / lu_solve - solve linear systems efficiently, re-using a factorisation
  • cho_factor / cho_solve - Cholesky solvers for positive-definite systems (Gaussian processes)

4. Sparse Arrays (scipy.sparse)

Efficient storage and operations for data that is mostly zeros: bag-of-words text features, user-item ratings and graphs.

Key concepts:
  • Formats: csr_array (fast row slicing and products), csc_array (fast columns), coo_array (easy construction)
  • Operations: matrix-vector products, slicing, stacking (sparse.hstack), conversions
  • Sparse linear algebra: scipy.sparse.linalg (svds, cg, lsqr)

Example: latent semantic analysis on a sparse document-term matrix

import numpy as np
from scipy import sparse
from scipy.sparse.linalg import svds

# 1,000 documents x 5,000 vocabulary terms, ~1% non-zero (like a bag-of-words matrix)
X = sparse.random_array((1000, 5000), density=0.01, format="csr", random_state=0)

print(f"stored values: {X.nnz:,} of {X.shape[0] * X.shape[1]:,}")
print(f"sparse memory: {(X.data.nbytes + X.indices.nbytes + X.indptr.nbytes) / 1e6:.2f} MB "
      f"vs dense: {X.shape[0] * X.shape[1] * 8 / 1e6:.0f} MB")

u, s, vt = svds(X, k=20, random_state=0)   # truncated SVD = latent semantic analysis
doc_topics = u * s                          # 1000 x 20 dense representation
print(doc_topics.shape, s[::-1][:5].round(3))

5. Spatial Algorithms (scipy.spatial)

Distance metrics, KD-trees and nearest-neighbour searches used in clustering, retrieval and outlier detection.

Highlights:
  • distance.pdist, distance.cdist - pairwise distances with many metrics
  • KDTree - fast nearest-neighbour and radius queries
  • ConvexHull, Delaunay - computational geometry utilities

Example: find the nearest stores for each customer

import numpy as np
from scipy.spatial import KDTree
from scipy.spatial.distance import cdist

rng = np.random.default_rng(5)
stores = rng.uniform(0, 100, size=(500, 2))      # (x, y) store locations
customers = rng.uniform(0, 100, size=(5, 2))

tree = KDTree(stores)
dist, idx = tree.query(customers, k=3)           # 3 nearest stores per customer
print("nearest store ids:\n", idx)
print("distances:\n", dist.round(2))

# Brute-force check with cdist on a small sample
print(np.allclose(np.sort(cdist(customers, stores), axis=1)[:, :3], dist))

6. Signal Processing (scipy.signal)

Filtering, spectral analysis and feature extraction for audio, sensor and time-series data.

Common tasks:
  • Design and apply filters: butter(..., output="sos") + sosfiltfilt (numerically safer than b, a + filtfilt)
  • Spectral features: welch, stft, spectrogram, find_peaks
  • Resampling: resample, resample_poly

Example: clean a noisy sensor signal and extract frequency features

The detected peaks (about 1 Hz and 25 Hz) are the movement signal and the interference; the exact values depend on the spectral resolution.

import numpy as np
from scipy import signal

fs = 100                                   # sensor sampled at 100 Hz
t = np.arange(0, 10, 1 / fs)
rng = np.random.default_rng(0)
clean = np.sin(2 * np.pi * 1.0 * t)        # 1 Hz movement signal
noisy = clean + 0.5 * np.sin(2 * np.pi * 25 * t) + 0.2 * rng.normal(size=t.size)

# 4th-order low-pass Butterworth filter at 5 Hz, applied forward and backward (zero phase)
sos = signal.butter(4, 5, btype="low", fs=fs, output="sos")
smoothed = signal.sosfiltfilt(sos, noisy)

print("error before:", np.sqrt(np.mean((noisy - clean) ** 2)).round(3))
print("error after: ", np.sqrt(np.mean((smoothed - clean) ** 2)).round(3))

# Frequency-domain features for an ML model
freqs, power = signal.welch(noisy, fs=fs, nperseg=256)
peaks, _ = signal.find_peaks(power, prominence=0.01 * power.max())
print("frequency peaks (Hz):", freqs[peaks].round(1))

7. Interpolation (scipy.interpolate)

Interpolate or smooth data, fill missing points, or create continuous functions from discrete samples.

Recommended APIs:
  • 1-D: np.interp (linear), make_interp_spline (splines), CubicSpline, PchipInterpolator (no overshoot)
  • Gridded N-D data: RegularGridInterpolator
  • Scattered N-D points: RBFInterpolator, griddata
  • Smoothing noisy data: make_smoothing_spline

Example: fill gaps in hourly readings and interpolate scattered points

import numpy as np
from scipy.interpolate import make_interp_spline, RBFInterpolator

# Hourly temperature readings with gaps (NaN)
hours = np.arange(12, dtype=float)
temps = np.array([12.1, 12.8, np.nan, 14.9, 16.2, np.nan, np.nan, 18.4, 18.1, 17.0, np.nan, 14.2])

known = ~np.isnan(temps)
spline = make_interp_spline(hours[known], temps[known], k=3)   # cubic spline
filled = np.where(known, temps, spline(hours))
print(filled.round(2))

# Scattered 2-D points (replaces the removed interp2d / legacy Rbf)
rng = np.random.default_rng(0)
points = rng.uniform(0, 1, size=(50, 2))
values = np.sin(3 * points[:, 0]) + np.cos(3 * points[:, 1])
rbf = RBFInterpolator(points, values, kernel="thin_plate_spline")
print(rbf(np.array([[0.5, 0.5], [0.2, 0.8]])).round(3))

8. Integration (scipy.integrate)

Numerical integration and ODE solvers, handy for simulation-based ML or probabilistic modelling.

Key functions:
  • quad, dblquad, nquad - integrals in 1-D / N-D
  • solve_ivp - initial value ODE problems (Runge-Kutta, BDF, ...)

9. FFT (scipy.fft)

Fast Fourier Transforms for frequency-domain analysis and feature engineering: fft, ifft, rfft, irfft, fftn and rfftfreq.

10. Image Processing (scipy.ndimage)

Basic image processing (filtering, morphology, measurements) for classical computer-vision pipelines: gaussian_filter, sobel, binary_erosion, binary_dilation and label for connected components.

SciPy Best Practices for ML

1. Start with NumPy arrays: keep data in NumPy/SciPy structures for performance.

2. Choose the right solver: try different minimize methods and supply gradients (jac) whenever you can.

3. Exploit sparsity: use scipy.sparse for large, mostly-zero feature matrices to save memory and time.

4. Validate statistically: back findings with proper tests and confidence intervals (bootstrap).

5. Profile your pipeline: a SciPy routine can often replace a slow Python loop.
