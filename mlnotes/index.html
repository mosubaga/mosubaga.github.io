Machine Learning

A practical guide to choosing the right algorithm, and to the Python libraries you will use at every step, with runnable code.

Machine learning is a branch of artificial intelligence that lets computers learn patterns from data and make predictions or decisions without being explicitly programmed for each case. Choosing the right algorithm for your problem matters as much as the data itself. This guide explains which algorithms suit which scenarios, and the companion pages show how to use the core Python libraries in practice.

Understanding Problem Types

Machine learning problems fall into three main categories. The right choice depends on whether you have labeled data, what kind of output you need, and how the learning signal is provided.

Supervised Learning

The model learns from a labeled dataset, where every training example comes with the correct answer. The goal is to learn a mapping from inputs to outputs so the model can generalise to new, unseen data.

Use cases: Email spam detection, house price prediction, medical diagnosis, image classification, sentiment analysis.

Unsupervised Learning

The model is given data without labels and must find hidden structure on its own. There is no "right answer" to optimise for. Instead the algorithm discovers patterns, groupings, or compact representations.

Use cases: Customer segmentation, anomaly detection, topic modeling, data compression, recommendation systems (collaborative filtering).

Reinforcement Learning

An agent interacts with an environment, takes actions, and receives rewards or penalties. It learns a policy (a strategy for choosing actions) that maximises cumulative reward over time. Unlike the other two paradigms there is no static dataset; experience is collected as the agent explores.

Use cases: Game-playing AI (Chess, Go, video games), robotics control, autonomous vehicles, personalised recommendations, and fine-tuning large language models from human feedback (RLHF).

Algorithm Selection Guide

Linear Regression

Problem Type: Supervised Learning - Regression

Use When: You need to predict continuous numerical values and the relationship between features and target is roughly linear.

Examples: House prices, demand forecasting, sales prediction, temperature trends.

Pros: Simple, fast, highly interpretable coefficients. Regularised variants (Ridge, Lasso) handle many correlated features.

Cons: Assumes linear relationships, sensitive to outliers.

Logistic Regression

Problem Type: Supervised Learning - Classification

Use When: You need binary or multi-class classification with linear decision boundaries, or well-calibrated probabilities.

Examples: Email spam detection, disease diagnosis (yes/no), customer churn prediction, credit scoring.

Pros: Probabilistic output, efficient, interpretable, a strong baseline (especially for text).

Cons: Limited to linear decision boundaries unless you engineer features.

Decision Trees

Problem Type: Supervised Learning - Classification & Regression

Use When: You need an interpretable model that captures non-linear relationships and feature interactions.

Examples: Credit approval rules, medical triage, customer segmentation.

Pros: Easy to explain, handles non-linear data, needs little preprocessing (no scaling).

Cons: Prone to overfitting, unstable with small data changes.

Random Forest

Problem Type: Supervised Learning - Classification & Regression

Use When: You want strong accuracy on tabular data with little tuning and can sacrifice some interpretability.

Examples: Fraud detection, churn prediction, feature importance analysis.

Pros: Robust, reduces overfitting compared to single trees, provides feature importance, few hyperparameters.

Cons: Less interpretable, larger models, slower predictions than linear models.

Support Vector Machines (SVM)

Problem Type: Supervised Learning - Classification & Regression

Use When: You have small to medium datasets with many features and need a clear margin between classes.

Examples: Text categorisation, bioinformatics, handwriting recognition.

Pros: Effective in high dimensions, flexible through kernel functions.

Cons: Kernel SVMs scale poorly beyond ~100k samples, require feature scaling, hard to interpret.

K-Nearest Neighbors (KNN)

Problem Type: Supervised Learning - Classification & Regression

Use When: You have small to medium datasets and want a simple, instance-based method.

Examples: Recommendation ("similar items"), pattern recognition, anomaly detection.

Pros: Simple to understand, no real training phase, naturally multi-class.

Cons: Slow predictions on large data, sensitive to irrelevant features, requires feature scaling.

K-Means Clustering

Problem Type: Unsupervised Learning - Clustering

Use When: You need to group similar data points without predefined labels.

Examples: Customer segmentation, image colour quantisation, document clustering.

Pros: Simple and fast, scales well to large datasets.

Cons: You must choose the number of clusters, sensitive to initialisation and scaling, assumes roughly spherical clusters.

Neural Networks (Deep Learning)

Problem Type: Supervised, Unsupervised & Self-supervised Learning

Use When: You have large amounts of data or unstructured inputs (images, audio, text) with complex patterns.

Examples: Image recognition, speech recognition, machine translation, large language models.

Pros: State-of-the-art on unstructured data; pre-trained models allow fine-tuning with modest data.

Cons: Computationally expensive, harder to interpret, often outperformed by gradient boosting on small tabular datasets.

Naive Bayes

Problem Type: Supervised Learning - Classification

Use When: You need a fast, probabilistic baseline, especially for text classification.

Examples: Spam filtering, sentiment analysis, document categorisation (see the NLTK page).

Pros: Very fast training and prediction, works well with high-dimensional sparse data.

Cons: Assumes feature independence, probabilities are often poorly calibrated.

Gradient Boosting

Problem Type: Supervised Learning - Classification & Regression

Use When: You want top predictive performance on structured/tabular data.

Libraries: scikit-learn's HistGradientBoosting*, XGBoost, LightGBM, CatBoost.

Pros: Excellent accuracy, handles missing values natively, provides feature importance.

Cons: Can overfit, needs careful tuning (learning rate, depth, number of trees).

Principal Component Analysis (PCA)

Problem Type: Unsupervised Learning - Dimensionality Reduction

Use When: You need fewer features while preserving as much variance as possible.

Examples: Visualisation, noise reduction, feature compression before another model.

Pros: Removes correlated features, speeds up downstream models.

Cons: Components are hard to interpret, captures only linear structure, sensitive to scaling.

DBSCAN / HDBSCAN

Problem Type: Unsupervised Learning - Clustering

Use When: You need clusters of arbitrary shape and want outliers flagged automatically.

Examples: Anomaly detection, geospatial hotspots, separating noise from signal.

Pros: No need to specify the number of clusters, finds arbitrary shapes, labels outliers. HDBSCAN copes with varying densities.

Cons: Sensitive to parameters (eps, min_samples), struggles in very high dimensions.

Try It: Compare Algorithms Fairly

Theory helps narrow the options; experiments decide. The script below evaluates seven of the algorithms above on the same dataset with the same 5-fold cross-validation. Notice that the simplest model, scaled logistic regression, comes out on top here. Always include a simple baseline.

from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import HistGradientBoostingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
from sklearn.naive_bayes import GaussianNB
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier

X, y = load_breast_cancer(return_X_y=True)

candidates = {
    "Logistic Regression": make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)),
    "Decision Tree":       DecisionTreeClassifier(max_depth=4, random_state=0),
    "Random Forest":       RandomForestClassifier(n_estimators=300, random_state=0),
    "SVM (RBF kernel)":    make_pipeline(StandardScaler(), SVC()),
    "K-Nearest Neighbors": make_pipeline(StandardScaler(), KNeighborsClassifier()),
    "Naive Bayes":         GaussianNB(),
    "Gradient Boosting":   HistGradientBoostingClassifier(random_state=0),
}

# Same data, same 5-fold cross-validation, same metric: a fair comparison
for name, model in candidates.items():
    scores = cross_val_score(model, X, y, cv=5, scoring="f1")
    print(f"{name:20s} F1 = {scores.mean():.3f} +/- {scores.std():.3f}")

Models that rely on distances or margins (logistic regression, SVM, KNN) are wrapped in a pipeline with StandardScaler; tree-based models do not need scaling.

Decision Framework

Step 1: Define your problem. Is it classification, regression, clustering, or dimensionality reduction?

Step 2: Understand your data. How much data do you have? Is it labeled? Is it tabular, text, images or time series?

Step 3: Consider constraints. Do you need interpretability? What is your compute budget? How fast must predictions be?

Step 4: Start simple. Begin with linear or logistic regression as a baseline before trying complex models.

Step 5: Iterate and evaluate. Compare models with cross-validation on the same metric, then refine the best candidates.
