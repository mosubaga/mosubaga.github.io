Library guide · Data preparation

Pandas

Load, clean, reshape and summarise tabular data, then hand it to a model.

Pandas is a data manipulation and analysis library built on top of NumPy. It provides high-level data structures and tools for working with structured data, making it indispensable for data preprocessing in machine learning projects. Pandas excels at tabular data, time series and complex transformations. For very large datasets or multi-core speed, also look at Polars.

pip install pandas

Why Pandas is Critical for Machine Learning

Pandas bridges the gap between raw data and machine learning models by providing:

  • DataFrame structure: an intuitive 2-D labeled table, similar to a spreadsheet or SQL table.
  • Data cleaning: tools for missing data, duplicates and type conversions.
  • Data transformation: filtering, grouping, merging and pivoting.
  • I/O capabilities: read and write CSV, Excel, Parquet, SQL, JSON and more.
  • Integration: works directly with NumPy, scikit-learn and plotting libraries.

What's new in pandas 3.x

  • Copy-on-Write is always on. Chained assignment such as df["col"][0] = 1 no longer modifies df; write df.loc[0, "col"] = 1 instead. Every derived DataFrame behaves like an independent copy.
  • Text columns use a dedicated string dtype (shown as str) instead of the generic object dtype.
  • Use df.to_numpy() rather than df.values, and the snake_case accessors such as .dt.day_of_week (the old .dt.dayofweek is deprecated).
  • Aggregations like df.groupby("g").mean() raise an error on non-numeric columns. Select the columns first, or pass numeric_only=True.

Core Pandas Data Structures

Series

A one-dimensional labeled array that can hold any data type, like a single column in a spreadsheet.

  • Has an index for accessing elements by label
  • Supports vectorised operations like NumPy arrays
  • Holds one dtype (integers, floats, strings, datetimes, categories)

DataFrame

A two-dimensional labeled table whose columns can have different types: the primary way to represent ML datasets.

  • Row and column labels for easy data access
  • Can be thought of as a dictionary of Series
  • Supports SQL-like operations (joins, group by, pivot)

A Practical Walkthrough

The following examples form one small project, cleaning and analysing an online store's orders. Run the steps in order in a single script or notebook; each step builds on the df from the previous one.

Step 1: Load and explore

The first step in any machine learning project is loading and understanding your data.

Loading data:
  • pd.read_csv(), pd.read_excel()
  • pd.read_parquet() - fast, typed, compressed
  • pd.read_sql(), pd.read_json()
Exploration:
  • df.head() / df.tail(), df.shape, df.dtypes
  • df.info() - types and non-null counts
  • df.describe() - statistical summary
  • df.isna().sum() - missing values per column
import io
import pandas as pd

csv_data = """order_id,date,customer,region,product,quantity,unit_price
1001,2026-01-05,Alice ,East,Laptop,1,1200
1002,2026-01-06,Bob,West,Mouse,3,25
1003,2026-01-06,Chen,East,Monitor,2,300
1004,2026-01-07,Dana,North,Laptop,,1150
1005,2026-01-08,alice,East,Keyboard,2,80
1006,2026-01-08,Evan,West,Monitor,1,
1007,2026-01-09,Bob,West,Laptop,1,1250
1007,2026-01-09,Bob,West,Laptop,1,1250
1008,2026-01-12,Chen,East,Mouse,4,25
1009,2026-01-13,Dana,North,Monitor,1,310
"""

# For a real file use: pd.read_csv("sales.csv", parse_dates=["date"])
df = pd.read_csv(io.StringIO(csv_data), parse_dates=["date"])

print(df.head())
df.info()
print(df.describe())
print(df.isna().sum())

Step 2: Clean and preprocess

Real-world data contains missing values, duplicates and inconsistencies. Here a duplicated order, inconsistent customer names and two missing values are fixed.

Missing data

isna(), dropna(), fillna()

Duplicates

duplicated(), drop_duplicates()

Type conversion

astype(), pd.to_datetime(), pd.to_numeric()

String cleanup

.str.strip(), .str.lower(), .str.replace()

# Remove exact duplicate rows (order 1007 was recorded twice)
df = df.drop_duplicates()

# Normalise messy text: "Alice " and "alice" become "Alice"
df["customer"] = df["customer"].str.strip().str.title()

# Fill missing values with sensible, explainable defaults
df["quantity"] = df["quantity"].fillna(1).astype("int64")
df["unit_price"] = df["unit_price"].fillna(
    df.groupby("product")["unit_price"].transform("median")
)

print(df.isna().sum().sum(), "missing values left")
print(df)

Step 3: Feature engineering

Create new features or transform existing ones to give a model more useful signals.

Common techniques:
  • Arithmetic columns: df["revenue"] = df["quantity"] * df["unit_price"]
  • Date parts: .dt.month, .dt.day_name(), .dt.day_of_week
  • Binning: pd.cut() / pd.qcut() to discretise continuous variables
  • One-hot encoding: pd.get_dummies() for categorical variables
  • Group statistics: groupby(...).transform() to add per-group aggregates to every row
df["revenue"] = df["quantity"] * df["unit_price"]
df["day_of_week"] = df["date"].dt.day_name()
df["is_weekend"] = df["date"].dt.day_of_week >= 5
df["order_size"] = pd.cut(
    df["revenue"],
    bins=[0, 100, 1000, float("inf")],
    labels=["small", "medium", "large"],
)

print(df[["order_id", "revenue", "day_of_week", "order_size"]])

Step 4: Select and filter

Selection methods:
  • Columns: df["column"] or df[["col1", "col2"]]
  • By label / position: df.loc[rows, cols] / df.iloc[rows, cols]
  • Boolean filtering: df[df["age"] > 25], combining conditions with & and |
  • Query strings: df.query('age > 25 and city == "Boston"')
# Boolean filtering: wrap each condition in parentheses, combine with & or |
big_east = df.loc[(df["region"] == "East") & (df["revenue"] > 500),
                  ["customer", "product", "revenue"]]
print(big_east)

# query() reads like SQL and is handy for quick exploration
print(df.query("quantity >= 2 and unit_price < 500"))

# Position-based selection: first 3 rows, first 4 columns
print(df.iloc[:3, :4])

Step 5: Group and aggregate

groupby splits data into groups, applies functions and combines the results. Named aggregation (new_name=("column", "func")) keeps the output readable.

summary = (
    df.groupby("region")
      .agg(orders=("order_id", "count"),
           revenue=("revenue", "sum"),
           avg_order=("revenue", "mean"))
      .sort_values("revenue", ascending=False)
)
print(summary)

# transform() returns one value per row - perfect for ML features
df["customer_total"] = df.groupby("customer")["revenue"].transform("sum")

pivot = pd.pivot_table(df, values="revenue", index="region",
                       columns="product", aggfunc="sum", fill_value=0)
print(pivot)

Step 6: Time series

With a datetime index you can resample to any frequency and compute rolling statistics, common features for forecasting models.

daily = (
    df.set_index("date")["revenue"]
      .resample("D").sum()          # one row per calendar day (gaps become 0)
)
rolling = daily.rolling(window=3, min_periods=1).mean()

print(pd.DataFrame({"daily": daily, "3_day_avg": rolling.round(1)}))

Step 7: Hand the data to a model

Most scikit-learn estimators accept DataFrames directly. When you need plain arrays, use .to_numpy(). For more robust preprocessing inside a model pipeline, see ColumnTransformer on the Scikit-Learn page.

# One-hot encode categoricals and hand the result to scikit-learn
features = pd.get_dummies(
    df[["quantity", "unit_price", "is_weekend", "region", "product"]],
    columns=["region", "product"],
    dtype="int64",
)
target = (df["revenue"] > 500).astype("int64")

X = features.to_numpy()      # prefer .to_numpy() over the older .values
y = target.to_numpy()
print(features.columns.tolist())
print(X.shape, y)

Pandas in Machine Learning Pipelines

Exploratory Analysis

Understand distributions and relationships with df.corr(numeric_only=True) and value_counts().

Preventing Leakage

Compute fill values and statistics on the training split only, or let a scikit-learn Pipeline do it for you.

Data Merging

Enrich features with pd.merge(), pd.concat() or df.join(). Use validate="m:1" to catch bad joins.

Time Series Splits

Sort by time and split chronologically; never shuffle future rows into the training set.

Advanced Pandas Techniques

Categorical dtype

For columns with few distinct values, df["col"].astype("category") saves memory and speeds up group-bys. Many models (such as HistGradientBoostingClassifier) can use categorical columns natively.

Method chaining

Chaining operations (df.query(...).assign(...).groupby(...).agg(...)) keeps each transformation readable and avoids temporary variables. With Copy-on-Write, chaining is also memory-efficient.

Large files

Store data as Parquet, read only the columns you need (usecols= / columns=), and use chunksize= to stream CSVs. If you outgrow a single core, Polars offers a lazy, multi-threaded alternative.

Pandas Best Practices for ML

1. Always examine your data first: head(), info() and describe() before processing.

2. Handle missing data thoughtfully: understand why data is missing before dropping or imputing.

3. Use vectorised operations: avoid iterrows(); prefer column arithmetic, .str/.dt accessors and np.where.

4. Be mindful of memory: use appropriate dtypes, category and Parquet.

5. Use .loc for assignment: it is the only reliable way to update values under Copy-on-Write.

6. Document transformations: keep preprocessing in functions or pipelines for reproducibility.
