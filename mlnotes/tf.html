TensorFlow

Using TensorFlow and Keras for classical machine learning: linear models, clustering and production-ready data pipelines.

TensorFlow is often associated with deep learning, but it is also a solid toolkit for traditional machine learning. With the Keras API you can build linear regression, logistic regression and even clustering using the same training loop, optimisers and data pipelines. This page focuses on classic ML tasks and keeps neural networks to a minimum.

pip install tensorflow scikit-learn

Quick link: for the scikit-learn way of doing the same tasks, visit the Scikit-Learn page.

Updated for TensorFlow 2.16+ and Keras 3

  • TensorFlow now ships with Keras 3. Declare inputs with tf.keras.Input(shape=(n,)) as the first layer; passing input_shape= to a layer is deprecated.
  • model.save() requires a .keras (or .h5) file name. To export a TensorFlow SavedModel for TF Serving or mobile, use model.export(path).
  • TensorFlow Lite has been renamed LiteRT for on-device inference.
  • Keras 3 is multi-backend: the same model code can also run on JAX or PyTorch with the standalone keras package.

Why Use TensorFlow for Non-Deep Learning?

Consistent training loop

compile(), fit() and callbacks work the same for every model.

Scales to large data

Mini-batch training with GPU/TPU acceleration when you need it.

Deployable

Export to SavedModel for TF Serving, or to LiteRT for mobile and edge.

Unified data pipeline

tf.data handles batching, shuffling, prefetching and preprocessing.

Workflow Overview

Step 1: Prepare data

Use NumPy arrays or a tf.data.Dataset; put normalisation inside the model with a Normalization layer.

Step 2: Define the model

For classical ML, a single Dense layer often is the entire model.

Step 3: Compile

Choose a loss and metrics that match the task: MSE/MAE, log loss, accuracy, AUC.

Step 4: Train and evaluate

Fit with a validation split and early stopping, then evaluate on a held-out test set.

Linear Regression with Keras

Linear regression is a single linear unit trained with mean squared error. The Normalization layer learns feature means and variances from the training data, so the saved model standardises new inputs automatically.

import numpy as np
import tensorflow as tf

# Synthetic housing data: price depends linearly on 3 features
rng = np.random.default_rng(0)
X = rng.normal(size=(2000, 3)).astype("float32")
true_w = np.array([30.0, -12.0, 8.0], dtype="float32")
y = (X @ true_w + 250.0 + rng.normal(0, 5, 2000)).astype("float32")
X_train, X_test, y_train, y_test = X[:1600], X[1600:], y[:1600], y[1600:]

# Normalization layer learns mean/std from the training data and lives inside the model
norm = tf.keras.layers.Normalization()
norm.adapt(X_train)

model = tf.keras.Sequential([
    tf.keras.Input(shape=(3,)),      # Keras 3 style (instead of input_shape=...)
    norm,
    tf.keras.layers.Dense(1),        # one Dense unit = linear regression
])
model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=0.1),
              loss="mse", metrics=["mae"])

early_stop = tf.keras.callbacks.EarlyStopping(patience=10, restore_best_weights=True)
model.fit(X_train, y_train, epochs=300, batch_size=64,
          validation_split=0.2, callbacks=[early_stop], verbose=0)

loss, mae = model.evaluate(X_test, y_test, verbose=0)
print(f"test MAE: {mae:.2f}")
Notes for linear regression:
  • Standardise features to speed up convergence (the Normalization layer does this).
  • Report mean absolute error (MAE), which is in the same units as the target.
  • EarlyStopping(restore_best_weights=True) stops when validation loss stops improving.

Logistic Regression with Keras

Logistic regression is a linear model with a sigmoid output (binary) or softmax output (multi-class). Adding an L2 kernel_regularizer gives you the same regularisation as scikit-learn's default.

import numpy as np
import tensorflow as tf
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X.astype("float32"), y.astype("float32"), stratify=y, random_state=0)

norm = tf.keras.layers.Normalization()
norm.adapt(X_train)

model = tf.keras.Sequential([
    tf.keras.Input(shape=(X.shape[1],)),
    norm,
    tf.keras.layers.Dense(1, activation="sigmoid",
                          kernel_regularizer=tf.keras.regularizers.L2(1e-3)),
])
model.compile(optimizer="adam", loss="binary_crossentropy",
              metrics=["accuracy", tf.keras.metrics.AUC(name="auc")])
model.fit(X_train, y_train, epochs=100, batch_size=32, validation_split=0.2, verbose=0)

results = model.evaluate(X_test, y_test, verbose=0, return_dict=True)
print({k: round(v, 3) for k, v in results.items()})

probs = model.predict(X_test[:5], verbose=0).ravel()
print("P(benign):", probs.round(3))
Multi-class variant:
  • Use Dense(num_classes, activation="softmax")
  • Use sparse_categorical_crossentropy for integer labels, or categorical_crossentropy for one-hot labels

Efficient Input Pipelines with tf.data

For datasets that do not fit in memory, or to overlap data loading with training, wrap your data in a tf.data.Dataset.

import numpy as np
import tensorflow as tf

rng = np.random.default_rng(1)
features = rng.normal(size=(10_000, 4)).astype("float32")
labels = (features.sum(axis=1) > 0).astype("float32")

dataset = (
    tf.data.Dataset.from_tensor_slices((features, labels))
      .shuffle(buffer_size=10_000, seed=1)
      .batch(256)
      .prefetch(tf.data.AUTOTUNE)       # overlap data loading with training
)

model = tf.keras.Sequential([tf.keras.Input(shape=(4,)),
                             tf.keras.layers.Dense(1, activation="sigmoid")])
model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=0.01), loss="binary_crossentropy", metrics=["accuracy"])
# the Dataset is already shuffled, so tell fit() not to shuffle again
history = model.fit(dataset, epochs=10, shuffle=False, verbose=0)
print("final accuracy:", round(history.history["accuracy"][-1], 3))

K-Means Clustering with TensorFlow

TensorFlow can run classic K-Means with fully vectorised tensor operations. This version samples initial centres from the data, computes all distances at once, updates centres with unsorted_segment_mean, handles empty clusters, and stops when the centres no longer move.

import numpy as np
import tensorflow as tf

rng = np.random.default_rng(3)
blobs = [rng.normal(loc=c, scale=0.5, size=(200, 2)) for c in ([0, 0], [4, 4], [0, 5])]
X = tf.constant(np.vstack(blobs), dtype=tf.float32)

k = 3
# Initialise centres by sampling k real data points
init_idx = tf.random.shuffle(tf.range(tf.shape(X)[0]), seed=3)[:k]
centers = tf.Variable(tf.gather(X, init_idx))

for step in range(50):
    # (n, 1, d) - (1, k, d) -> (n, k) squared distances, fully vectorised
    dists = tf.reduce_sum((X[:, None, :] - centers[None, :, :]) ** 2, axis=2)
    assign = tf.argmin(dists, axis=1, output_type=tf.int32)
    new_centers = tf.math.unsorted_segment_mean(X, assign, num_segments=k)
    # keep the old centre if a cluster ends up empty
    counts = tf.math.bincount(assign, minlength=k)
    new_centers = tf.where(counts[:, None] > 0, new_centers, centers)
    if np.allclose(new_centers.numpy(), centers.numpy()):
        break
    centers.assign(new_centers)

inertia = tf.reduce_sum(tf.reduce_min(dists, axis=1)).numpy()
print(f"stopped after {step + 1} steps, inertia={inertia:.1f}")
print(np.round(centers.numpy(), 2))
Clustering tips:
  • Normalise features so one dimension does not dominate the distance.
  • Run several random initialisations and keep the one with the lowest inertia.
  • For everyday use, scikit-learn's KMeans (k-means++ initialisation) is simpler; the TensorFlow version shines when the data is already on a GPU.

Saving and Deploying Models

import numpy as np
import tensorflow as tf

model = tf.keras.Sequential([tf.keras.Input(shape=(3,)), tf.keras.layers.Dense(1)])
model.compile(optimizer="adam", loss="mse")
model.fit(np.random.rand(64, 3), np.random.rand(64), epochs=1, verbose=0)

model.save("linear_model.keras")                      # native Keras format
restored = tf.keras.models.load_model("linear_model.keras")
print(restored.predict(np.ones((1, 3)), verbose=0))

model.export("linear_model_savedmodel")               # SavedModel for TF Serving / LiteRT

Best Practices for Classical ML in TensorFlow

Keep models linear: one Dense layer gives you linear or logistic regression.

Put preprocessing in the model: Normalization and other preprocessing layers travel with the saved model.

Monitor metrics: MAE for regression; AUC or F1 for imbalanced classification.

Use validation data and early stopping: even simple models can overfit.

Track experiments: log hyperparameters and seeds (tf.keras.utils.set_random_seed) for reproducibility.
