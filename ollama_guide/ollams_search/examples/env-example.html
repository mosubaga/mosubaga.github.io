examples/.env.example

Optional Ollama API key, model tag and context length settings.

bash 12 lines Download raw file
bash
# Copy the values you need into your shell profile or a local .env file.
# Never commit real keys.

# Required only for search_agent.py (Ollama's hosted web search API).
# Create a key at https://ollama.com/settings/keys
OLLAMA_API_KEY=your_api_key_here

# Optional: model tag exactly as shown by `ollama list`.
OLLAMA_MODEL=qwen3:8b

# Optional: context window requested per chat call. Needs enough memory.
OLLAMA_NUM_CTX=32000
