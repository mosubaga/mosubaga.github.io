What this does and does not do

A local model cannot reach the internet by itself. This handbook shows three ways to give it a search tool: Ollama's own web search API, an MCP host with a search server, and a tool function you write yourself. In each case the model runs locally on Ollama while the search itself goes out to a search service; therefore the overall workflow is not fully offline, and your search queries leave your computer.

Web search supplies current text, not guaranteed truth. A small model such as qwen3:8b can skip the search, misread a snippet, or combine sources incorrectly. The examples print every tool call, limit the number of steps, and ask the model to cite URLs so that you can check the answer. They only read from the web; they do not execute model-generated commands.

Each example agent comes in Python and TypeScript. Both versions of ddg_search_agent were run against a local qwen3:8b when this handbook was written. Both versions of search_agent follow Ollama's documented agent loop and need your own API key to run. Tools in this area change quickly: confirm install commands against each project's page.
