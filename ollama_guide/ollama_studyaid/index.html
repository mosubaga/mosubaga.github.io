What this does and does not do

This handbook shows how to study any subject, from mathematics and the sciences to history and computer science, with a model that runs on your own computer. The supplied examples use a downloaded chat model and a downloaded embedding model, so the workflow runs fully offline and your PDFs are not uploaded anywhere. That changes if you select a cloud model or one of the internet-backed MCP servers in chapter 05.

A local model is a study partner, not an authority. It can misread a passage, scramble a formula that was extracted badly from the PDF, or answer from memory instead of from your book. The examples print the pages they used, ask the model to cite them, and refuse to overwrite existing flashcard files. Check answers and cards against the textbook, and follow your institution's rules on AI use in assessed work.

All four example programs were run against a local qwen3:8b and embeddinggemma on a short sample PDF when this handbook was written. The app and MCP recipes in chapter 05 are assembled from each project's documentation and were not run. Tools in this area change quickly: confirm install commands against each project's page.
