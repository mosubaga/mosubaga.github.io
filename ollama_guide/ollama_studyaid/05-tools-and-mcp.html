1. Apps with document chat built in

If you would rather not run scripts, several applications do the extract, index and ask steps for you and can use Ollama as the model backend.

AppTypeNote
Open WebUIBrowser chat UI, self-hostedUpload files into a Knowledge collection and reference it in a chat; uses Ollama for chat and embeddings
AnythingLLMDesktop appWorkspaces of documents with built-in RAG; Ollama can be selected as the model provider
Page AssistBrowser extensionA sidebar for local Ollama models, with chat over documents and web pages
LM StudioDesktop appAttach documents to a chat; uses its own model runtime instead of Ollama

These tools hide the chunk size, the number of passages retrieved and the prompt. When an answer is wrong, the questions from chapter 03 still apply: did the search return the right passage, and was the text extracted correctly? Features and menus change between versions; follow each project's current documentation.

2. How MCP fits in

The Model Context Protocol (MCP) is a standard way to offer tools to a model. Ollama is an LLM runtime, not an MCP client, so you need a host application that connects to MCP servers and uses Ollama for inference.

text
Ollama (qwen3, local) <--> MCP host / client <--> MCP servers: PDF reader, Anki, Zotero, ...
HostTypeNote
ollmcpTerminal appBuilt for Ollama; Python 3.11+; can ask for approval before each tool call
mcphostCommand-line hostWritten in Go; select the model as ollama/<tag>
Open WebUIBrowser chat UINative MCP support from v0.6.31, Streamable HTTP servers only

The model must support tool calling. Check that ollama show qwen3:8b lists tools under Capabilities.

These are community and vendor projects that change quickly. Check each README for current install commands. The first six work offline; arXiv and Wikipedia servers send your queries to those services.

4. Recipe: ollmcp with a PDF reader and Anki

Requirements: Ollama with qwen3:8b, Python 3.11+, uv, Node.js, and Anki running with the AnkiConnect add-on.

bash
# Install the MCP client
uv tool install --upgrade ollmcp

# Register a document converter and the Anki server (everything after -- is the command to run)
ollmcp mcp add markitdown -- uvx markitdown-mcp
ollmcp mcp add anki -- npx -y @ankimcp/anki-mcp-server --stdio

# Confirm they are registered, then start chatting with the local model
ollmcp mcp list
ollmcp --model qwen3:8b

Inside the client, use /tools to see what is enabled, then ask in plain language:

text
Convert file:///Users/me/study/week4-slides.pdf to Markdown, then make 8 flashcards
from it and add them to my Anki deck "Biology 201". Show me the cards before adding them.

Important: A converter tool returns the whole document into the conversation. That suits lecture slides, a paper or one chapter. A full textbook will overflow the context window; use the index from chapter 03 for that. Raise num_ctx in the client's model settings before working with documents.

This recipe is assembled from each project's documentation and was not run for this handbook.

6. Keep it small and safe

  • Every tool description consumes context, and small models choose worse as the list grows. Enable only the two or three tools you need for the session.
  • An MCP server is a program running on your machine with your permissions. Install servers only from sources you trust.
  • Give file tools access to one study folder, read-only, not your whole home directory.
  • Review changes before they are made. ollmcp can ask for approval before each tool call; keep that on for tools that write, such as adding Anki cards.
  • Text inside a document can contain instructions aimed at the model. Treat document content as reference material, and be cautious with files from unknown sources.

7. Verify before you rely on it

text
Before trusting an answer or a flashcard:
1. Check that it cites a page, and that the page was among those retrieved.
2. Open the page and confirm it says what the answer claims.
3. Recompute any number, formula or derivation yourself.
4. Compare formulas and tables with the PDF; extraction can scramble them.
5. Treat anything without a page reference as the model's memory, not the book.
6. When the model and the textbook disagree, the textbook wins. Ask your instructor if unsure.

A local model makes practice cheap and private. It does not make it correct by default; the checks above are part of the method.
