1. Give it the pages first

Every technique here starts the same way: extract the pages you are studying and put them in the prompt, so the model works from your book and not from memory.

python
import pymupdf
from ollama import chat

def read_range(pdf_path: str, first: int, last: int) -> str:
    """Text of pages first..last (1-based), each labelled with its page number."""
    with pymupdf.open(pdf_path) as doc:
        return '\n\n'.join(
            f'[p. {n}] ' + ' '.join(doc[n - 1].get_text().split())
            for n in range(first, min(last, doc.page_count) + 1)
        )

pages = read_range('textbook.pdf', 40, 52)
response = chat(
    model='qwen3:8b',
    messages=[{'role': 'user', 'content':
        'Using only these pages, list the five ideas I must understand, '
        'each with the page it is on.\n\n' + pages}],
    options={'num_ctx': 16000},
)
print(response.message.content)

Set num_ctx large enough for the pages plus the answer. Ten to fifteen pages of prose fit in 16,000 tokens; if answers ignore the later pages, the text was truncated and you should choose a smaller range.

2. Explain and summarize

Ask for a specific kind of explanation. A vague request gets a vague summary.

text
Using only the pages below:
1. Explain the main argument in 5 sentences for someone who has not read it.
2. Define each technical term the first time you use it.
3. Give one worked example from the text, with its page number.
4. List what the pages assume I already know.
Do not add material that is not on these pages.

Useful variations: "explain it to a first-year student", "explain how this differs from [earlier concept]", "what would a wrong but tempting understanding of this be?". Reading a summary feels productive but is weak practice on its own; follow it with sections 3 to 5.

3. Flashcards for Anki

Spaced repetition software such as Anki schedules reviews for you. The example program turns a page range into a file Anki can import. It uses structured outputs: passing a JSON schema as format forces the reply into that shape, so the script can parse it reliably.

bash
python flashcards.py textbook.pdf --pages 40-52 --count 10 --out cards.tsv
npx tsx flashcards.ts textbook.pdf --pages 40-52 --count 10 --out cards.tsv
python
from pydantic import BaseModel

class Card(BaseModel):
    front: str   # the question
    back: str    # the answer
    page: int    # page the answer comes from

class Deck(BaseModel):
    cards: list[Card]

response = chat(
    model='qwen3:8b',
    messages=[{'role': 'user', 'content': prompt}],
    format=Deck.model_json_schema(),   # the reply must match this schema
    think=False,
    options={'num_ctx': 16000, 'temperature': 0},
)
cards = Deck.model_validate_json(response.message.content).cards

Output from a run with qwen3:8b: one card per line, with front, back and a page tag separated by tabs.

text
What is the net gain of ATP during glycolysis?	A net gain of 2 ATP and 2 NADH per glucose molecule.	p6
What is the purpose of fermentation in the absence of oxygen?	To regenerate NAD+ so that glycolysis can continue.	p7

In Anki choose File > Import, select cards.tsv, and map the three fields to Front, Back and Tags. Read every card against its page before you study it. Memorizing a wrong card is worse than having no card. Full source: flashcards.py and flashcards.ts.

4. Practice questions

Have the model ask and you answer. Keep the answers hidden until you have tried.

text
You are writing a practice quiz from the textbook pages below.
Write 6 questions: 2 that test recall, 2 that ask me to explain why, and 2 that
ask me to apply an idea to a new case. Number them. Do not show the answers.
After I reply, grade each answer as correct, partly correct or incorrect,
quote the sentence from the pages that settles it, and give its page number.

For exam preparation, paste a past exam question as a model and ask for new questions "in the same style and difficulty". For problem-based subjects, ask for the problem only, solve it on paper, then ask the model to check your working line by line rather than to produce its own solution.

5. A Socratic tutor

A Modelfile saves a system prompt and settings as a named model, so the tutor is one command away. Save this as Modelfile:

text
FROM qwen3:8b
PARAMETER num_ctx 16000
PARAMETER temperature 0.3
SYSTEM """You are a patient tutor for a university student.
Do not give the final answer straight away. Ask one guiding question at a time,
wait for the student's reply, and correct mistakes by pointing to the idea that was missed.
When the student is right, say so briefly and move to the next step.
If the student pastes textbook pages, base your questions on them and cite page numbers.
If you are not sure of a fact, say so instead of guessing."""
bash
ollama create study-tutor -f Modelfile
ollama run study-tutor

Then explain a topic in your own words and let it question you. This is the Feynman technique: you find the gaps in your understanding by trying to teach. A small model does not always follow the "do not give the answer" rule; if it starts lecturing, tell it "ask me, don't tell me". Remove the model later with ollama rm study-tutor.

6. By subject

SubjectUseful requestsCheck
MathematicsExplain the idea behind a proof; find the first wrong line in my working; generate similar exercisesEvery calculation, by hand or with a computer algebra system. Extracted formulas against the page
SciencesCompare two processes in a table; explain a mechanism step by step; predict what changes if one condition changesUnits, constants and numbers against the textbook
History and social sciencesSummarize an author's argument and evidence; contrast two interpretations; build a timeline with page referencesDates, names and quotations. The model may blend the book with what it remembers
Computer scienceTrace an algorithm on a small input; explain complexity; write test cases for my codeRun the code. Do not accept claimed output
Graduate readingState the paper's question, method and main result; list its stated limitations; draft questions for a seminarClaims about what a paper found, against the paper itself

7. What to avoid

  • Asking without the pages. The answer then comes from the model's memory, with no page to check.
  • Accepting references it invents. A model can produce plausible titles and page numbers that do not exist. Only trust citations to pages you supplied.
  • Replacing the reading. Use summaries to preview or review a section, not to skip it.
  • Submitting its text as yours. Follow your institution's rules on AI use in assessed work.
