Getting Text out of Textbook PDFs

Extract text page by page, handle scanned books with OCR, and deal with formulas and tables.

1. Check for a text layer

A PDF either contains real text (you can select and copy it) or only page images (a scan). The model can only read text, so check first:

bash
python -m pip install pymupdf
python
import pymupdf

with pymupdf.open('textbook.pdf') as doc:
    with_text = sum(1 for page in doc if page.get_text().strip())
    print(f'{with_text} of {doc.page_count} pages contain text')

If most pages contain text, continue with section 2. If few or none do, the book is scanned and needs OCR (section 3).

2. Extract text page by page

Keep the page number with the text. It is what lets the model cite a page and lets you verify the answer.

python
import pymupdf

def read_pages(pdf_path: str) -> list[tuple[int, str]]:
    """Return (page number, text) for every page that has text."""
    pages = []
    with pymupdf.open(pdf_path) as doc:
        for number, page in enumerate(doc, start=1):
            text = ' '.join(page.get_text().split())
            if text:
                pages.append((number, text))
    return pages

for number, text in read_pages('textbook.pdf')[:3]:
    print(number, text[:80])

In TypeScript, unpdf wraps Mozilla's PDF.js and returns one string per page:

bash
npm init -y
npm install unpdf
npm install -D typescript tsx @types/node
typescript
import { readFile } from 'node:fs/promises';
import { extractText, getDocumentProxy } from 'unpdf';

async function readPages(pdfPath: string): Promise<{ page: number; text: string }[]> {
  const pdf = await getDocumentProxy(new Uint8Array(await readFile(pdfPath)));
  const { text } = await extractText(pdf, { mergePages: false });
  return text
    .map((raw, i) => ({ page: i + 1, text: raw.replace(/\s+/g, ' ').trim() }))
    .filter((p) => p.text.length > 0);
}

async function main(): Promise<void> {
  for (const p of (await readPages('textbook.pdf')).slice(0, 3)) {
    console.log(p.page, p.text.slice(0, 80));
  }
}

main().catch(console.error);

The number is the position in the PDF file, which usually differs from the number printed on the page because of the cover, preface and contents. Note the offset once (for example, PDF page 25 is printed page 1) so you can find a cited page in a paper copy.

3. Scanned books need OCR

OCRmyPDF adds a text layer to a scanned PDF, using the Tesseract OCR engine, and leaves the page images unchanged:

bash
ocrmypdf scanned.pdf searchable.pdf

Then use searchable.pdf everywhere else in this handbook. For a language other than English, pass the Tesseract language code, for example -l deu. OCR makes mistakes on small print, handwriting and formulas; spot-check a few pages before indexing a whole book.

4. Formulas, tables and figures

Plain text extraction works well for prose. It works poorly for three things that matter in technical subjects:

  • Formulas often come out scrambled: fractions lose their structure, and superscripts and Greek letters may be dropped or reordered.
  • Tables lose their columns and become a run of numbers.
  • Figures are not text at all; only the caption survives.

Tools that convert a PDF to Markdown keep more structure, including headings and tables, and some reconstruct equations as LaTeX:

ToolWhat it doesNote
PyMuPDF4LLMFast PDF to Markdown with headings and tablesLightweight; a good first step up from plain text
DoclingLayout analysis, tables, formulas, OCRRuns local models; slower, better on complex layouts
MarkerPDF to Markdown with equations as LaTeXAimed at books and scientific papers; check its license terms
MarkItDownConverts PDF, Word, PowerPoint and more to MarkdownAlso handles lecture slides; available as an MCP server (chapter 05)
bash
python -m pip install pymupdf4llm
python
import pymupdf4llm

# One Markdown string for selected pages (0-based page numbers)
markdown = pymupdf4llm.to_markdown('textbook.pdf', pages=[39, 40, 41])
print(markdown[:500])

# Or one entry per page, each with its own text and metadata
pages = pymupdf4llm.to_markdown('textbook.pdf', page_chunks=True)
print(len(pages), pages[0]['text'][:200])

Important: For mathematics, physics and chemistry, always compare an extracted formula with the page before you trust an answer built on it. If the extracted text is wrong, the model's answer will be wrong in a way that looks convincing.

5. Lecture slides and notes

The same approach works for other course material. Export slides to PDF, or convert Word and PowerPoint files to Markdown with MarkItDown. Typed notes in Markdown or plain text need no conversion at all. Handwritten notes need OCR and usually give poor results; typing a summary is more reliable.

6. Handle the files responsibly

  • Use PDFs you have the right to use: books you bought, open textbooks, library copies within their terms, and your own notes.
  • Extracted text and index files contain the book's content. Keep them on your machine and do not share or publish them.
  • Because everything runs locally, nothing in this workflow uploads the book. That changes if you switch to a cloud model or a hosted tool; check before you do.
