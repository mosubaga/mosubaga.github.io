Ollama Essentials for Coding

Install Ollama, pick a coding model, and call the local API from Python and TypeScript.

1. Basic commands

Install Ollama from ollama.com. Then open Terminal or PowerShell:

bash
ollama --version
ollama list
ollama pull qwen2.5-coder:7b
ollama run qwen2.5-coder:7b
ollama ps
ollama show qwen2.5-coder:7b

pull downloads a model; run launches it and may download it if missing; list displays local models. Model sizes and memory needs vary by quantization and context size.

Important: The model name in the supplied notes, qwen36:b, is ambiguous, and should be verified via ollama list. Do not assume it is a valid Ollama tag; use the exact installed model name in scripts (OLLAMA_MODEL).

2. Coding model candidates

Model/tag Reason to try Practical note
qwen2.5-coder:7b Compact coding baseline 4.7 GB download in the registry; suitable first trial
qwen2.5-coder:14b Larger coding reasoning 9.0 GB download; higher memory demand
qwen2.5-coder:32b Larger code-focused model ~20 GB download; requires substantial memory
qwen3-coder:30b Agent-oriented coding and tool use ~19 GB download; benchmark locally for speed/memory
qwen3-coder-next Newer local agentic-coding option Verify available tags and hardware fit in registry
deepseek-coder:6.7b Alternative for code generation Older model; benchmark against Qwen

Registry links: Qwen 2.5 Coder, Qwen 3 Coder, model search.

For machines with 16–24 GB RAM, start with a 7B coding model; consider larger models only after evaluating memory footprint and performance. Download size is not the same as runtime RAM usage. Larger context windows require additional memory. Model support for tool calling varies: inspect the registry and test real tool-call behavior.

3. Check local API

Ollama typically exposes an API at http://127.0.0.1:11434. If needed, run ollama serve (on some installations the service already starts automatically).

bash
curl http://127.0.0.1:11434/api/tags
bash
curl http://127.0.0.1:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen2.5-coder:7b","stream":false,"messages":[{"role":"user","content":"Write a Go HTTP handler with unit tests."}]}'

The commands above use Bash syntax. In Windows PowerShell, use Invoke-RestMethod:

powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:11434/api/tags'
$body = @{
    model = 'qwen2.5-coder:7b'
    stream = $false
    messages = @(@{ role = 'user'; content = 'Write a Go HTTP handler with unit tests.' })
} | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri 'http://127.0.0.1:11434/api/chat' -Method Post -ContentType 'application/json' -Body $body

4. Python SDK

bash
python -m pip install ollama
python
from ollama import chat

response = chat(
    model="qwen2.5-coder:7b",
    messages=[{"role": "user", "content": "Explain Go interfaces with an example."}],
)
print(response.message.content)

5. TypeScript SDK

bash
npm init -y
npm install ollama
npm install -D typescript tsx @types/node
typescript
import ollama from 'ollama';

const response = await ollama.chat({
  model: 'qwen2.5-coder:7b',
  messages: [{ role: 'user', content: 'Write a Java JUnit 5 test.' }],
});
console.log(response.message.content);

Optional cleanup after completing the examples: ollama rm qwen2.5-coder:7b deletes the downloaded model. Run ollama pull qwen2.5-coder:7b again before using it in later API or SDK calls.

6. Prompt structure

text
Role: You are a careful senior software engineer.
Target: Python 3.13 with FastAPI; use only documented APIs.
Task: Build a CRUD endpoint with tests.
Constraints: Small dependency set, type hints, no invented methods.
References: [insert retrieved official documentation and matching versions]
Output: File-by-file code, commands to run tests, assumptions and risks.

For reproducibility, record the model tag, package versions, documentation retrieval time, and test output.
