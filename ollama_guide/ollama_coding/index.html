What this does and does not do

The supplied examples default to a downloaded local Ollama model. Selecting a cloud model can send inference requests to Ollama’s cloud even through a localhost endpoint. Context7 connects over the internet (unless you provide your own local documentation source); therefore the overall workflow is not fully offline. Context7 fetches library documentation but does not guarantee that it is the newest release or that every API is correct. Check the installed dependency version, official release notes, and run tests.

The examples generate suggestions and write Markdown proposals to output/ by default, or to the directory selected with --out. They refuse to overwrite existing proposal files and do not execute model-generated commands. Choose a new --out directory for each run. Review changes before executing them. The examples use the Context7 REST API for straightforward code; the guide also explains true MCP integration. These are separate approaches to the same documentation source.
