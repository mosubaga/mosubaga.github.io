Before you start

All three handbooks assume Ollama is installed and running. Install it from ollama.com, then open Terminal or PowerShell:

bash
ollama --version
ollama pull qwen3:8b
ollama run qwen3:8b "Say hello in one sentence."
ollama list

Each handbook names the models it uses. Use the exact tags shown by ollama list on your machine.

What the handbooks share

  • The model runs locally. Inference happens on your computer when Ollama runs a downloaded model. A localhost endpoint alone does not guarantee this, because Ollama can also route requests to cloud models; check the selected model with ollama ps.
  • The model gets outside information from your program, not by itself. Library documentation, web search results and textbook pages are all retrieved by a script, an MCP host or an app, and then given to the model.
  • Answers should point to a source. Every workflow asks the model to cite a documentation URL, a web page or a textbook page, so that you can check it.
  • A small model makes mistakes. Model size, context length and memory all limit quality. Review code before running it, open the cited pages, and verify numbers yourself.

Tools in this area change quickly. Each handbook lists its primary sources; confirm install commands against them.
